## 项目与专刊的关系

本项目对应系统级理论中的错误累积、反馈动态与失败传播，并结合 Memory & Context Management、Evaluation & Benchmarking 两类技术主题。论文围绕“恢复后状态如何解释并预测可靠性”展开，将机制模型、真实环境干预与独立预测连成一条论证。

需要形成的核心证据为：相同状态分叉下的错误影响，冻结参数后的跨恢复条件预测，以及相对简单／灵活基线的增益与失效边界。第二骨干和受控长任务用于说明适用范围，按主结果决定规模。

征稿要求英文原创研究，且不能同时在其他期刊或会议审稿。若后续采用已发表会议论文的扩展稿，需核对 TIST 与 ACM 的扩展政策；提供的 PDF 提到至少 25% 新增内容。本项目目前按原创研究稿组织。

## 稿件组织

问题与近邻 → 恢复状态及事件模型 → 干预识别协议 → 跨条件预测 → 机制与边界分析 → 复现工件。运行日志、任务清单、配置、模型版本和评估脚本构成实验工件；原始数据及模型遵守各自许可。
