## 2. 用实际标签检查第二次成功预测

保持原系数和任务潜变量先验，用实际首轮失败及新反思类别更新潜类权重，再计算第二次成功概率。该计算使用当前可见信息，不读取第二轮结果作为预测输入；它是采集后的条件检查，不替代起点冻结的主要评分。

纠正组53条记录的预测成功数之和为7.35，实际9；删除组为3.03，实际7。删除组原先从起点预测的失败后第二次成功率约5.68%，对应约3.01条成功；换成实际新反思类别后仍为约3条。因此，仅修正E/C/B/U/A的写入比例不足以消除该组成功数偏差。

## 3. 七条删除组成功轨迹的共同事实

逐条检查七条第二次成功轨迹发现：旧E均在可见窗口中；新反思类别为E2、U2、A3，没有C。七条轨迹均未先提交将目标物放入微波炉的动作，而是持有目标物执行`heat … with microwave …`，收到成功加热观察，随后放到任务要求的位置并获得原生won。

其中六条先尝试取出微波炉中的其他物体，得到`Nothing happens.`，然后直接加热目标物。这些事实说明记忆文字与执行动作需要分别测量：Agent可以仍然读到错误前提，却在本次轨迹中没有执行相应的错误放置步骤。它们不能单独证明某类反思造成成功，因为这里的七条案例按成功结果选取。

公开案例表保存反思类别、成功加热动作、观察、任务ID和检查点摘要，完整轨迹仍在服务器。后续在新数据中同时记录目标错误动作尝试、环境接受、反思类别和任务结果，才能区分状态暴露与行为执行。

## 4. FloorPlan26为什么损失较大

该场景六个任务中，C与N组两次内分别成功2/6，低于各自49.61%的冻结预测；删除组成功3/6，高于11.75%的预测。删除条件的场景内Brier差为−0.08285，是总场景差−0.01084的主要负贡献；重复错误条件则贡献+0.04741。

C与N组各有五条首轮失败，新反思中分别有2条E；代入实际类别后，两组第二次成功数均预测约1.03，实际各1条。这一部分误差更多来自首轮成功机会，而不是这两个条件中第二次更新的类别分布。该场景的误差包含不同环节，不能统一归因于反思生成质量。
