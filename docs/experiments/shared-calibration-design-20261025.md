# 新任务上的共同机制校准

日期：2026-10-25。接续[原生语句干预](native-clause-20261025.md)和[失败经历与反思更新分析](../research/failure_feedback_and_reflection_update.md)。本批解决共同成功概率与自然反思更新概率如何估计的问题，为随后冻结的跨条件预测准备参数。

## 1. 这轮结果与理论的关系

上一批在三条非空记忆和相同背景文字下，仅修改目标表达，纠正组相对原错误组的首轮成功率提高30.56个百分点，调整后97.5%区间为[5.56,55.56]。同一失败输入下，纠正也降低了生成目标错误的比例。这两项结果分别支持成功机制和条件反思更新受记忆影响。

它们提供了建模依据。多轮成功率还取决于自然发生的失败经历、失败后生成什么反思、这些内容在后续窗口中如何起作用。纠正与删句的成功率差仍未分辨；之前重复错误起点的两轮预测偏差仍需要解释。本批直接采集完整尝试及其自然续行，从同一批新任务估计共同参数。

## 2. 数据分区与样本精度

从ALFWorld train中的未调用加热任务选择样本。排除全部既有公开任务、私有调用身份中的任务及其game/trajectory重复摘要，并排除134任务留出的四个场景。只使用清单和文件身份选择，不按任务结果筛选。

已检查的候选池含421个新任务、27个场景。以固定种子2026102502排序场景：18个场景用于校准，余下9个场景为后续预测保留；每个场景按任务摘要顺序选择两个任务，得到36个校准任务和18个保留任务。保留清单本批不重置环境、不调用模型。原134任务保持封存。

这些场景在前期开发中出现过；本分区保证本批共同模型的拟合与后续预测按场景分开。全部模型只拟合本批校准数据。内部比较采用整场景留一法，同一场景的两个任务及其所有条件始终同进同出。

以18个场景为主要统计单元，任务嵌套其中。旧pilot的三种子平均任务差值标准差约0.4134；本批每状态只有一种子，直接代入会低估随机波动。若暂以该数为参考，36个独立任务的正态半宽约13.5个百分点；每场景两个任务、相关系数0.5或1时约为16.5或19.1个百分点。这些数是乐观的精度参照。本批用途为机制校准和模型筛选；正式预测样本量将由整场景留出分数的方差、预定预测误差容差和成本共同确定。

## 3. 采集矩阵

继续固定Qwen3-8B BF16、原作者Reflexion、49个动作决策上限、每次最多256输出token，以及既有非思考模板、动作行和工具别名接口。Actor与reflector都读取最近三条反思；失败后执行一次原生反思更新，环境和对话在下一次尝试时重置。

E/C/N使用既有匹配短规则：E要求加热前将物体放进微波炉，C要求在微波炉处加热时将物体保留在物品栏，N为通用继续任务计划。每个任务执行以下七个起点，条目从旧到新排列：

| 条件 | 起始可见记忆 | 对应问题 |
|---|---|---|
| error_middle | [N,E,N] | 单个目标错误 |
| correct_middle | [N,C,N] | 相同长度与位置的正确说明 |
| neutral_full | [N,N,N] | 无目标规则的三条非空记忆 |
| repeated_error | [E,N,E] | 重复错误 |
| correct_latest | [E,N,C] | 纠正最新错误，保留旧错误 |
| delete_latest | [E,N] | 删除最新整条错误反思，改变长度与退出时间 |
| correct_oldest | [C,N,E] | 相同E/C数量、相反顺序 |

共36×7=252条轨迹，每条最多两次尝试，成功即停，最多504次完整尝试。七个条件分别使用模型种子2110至2116，每个任务内条件使用不同种子，避免人为共享同一随机数流影响任务异质性估计。比较仍在同一基础任务内配对，种子不作为独立任务计数。

第二次尝试直接使用首次失败后生成的完整原生反思，既不压缩为短规则，也不再次实施恢复。保存完整记忆，作者函数自行读取末三条；所有环境重置、预算、记忆身份和原生更新均逐条核对。

## 4. 状态与共同模型

状态程序保留实际长度和最近三条的有序类型及来源。短规则类型为E/C/N；新原生反思按实际建议标注：

- E：明确建议目标错误前提，没有正确替代建议。
- C：明确建议正确物品栏前提，没有目标错误建议。
- B：同时保留两种相互矛盾的建议，且没有解决矛盾。
- U：没有表达这两种目标前提，可以包含其他建议。
- A：指代或顺序含糊，不能可靠判断目标前提。

描述过去做错了什么不等于继续建议该错误。B表示明确冲突，A表示判断不清，两者分别保留。按全文内容摘要标注，由Codex阅读文本完成，记录理由和无人工第二复核状态。既有A标签保持原样。

比较三组少量共享特征：常数；实际长度、原生条目数量、A数量、是否有E及E剩余退出轮数；有序信息扩展进一步使用三个位置的E/C指示及共同出现指标。B同时触发E与C。每个模型在全部条件间共享系数，不读取操作名称、任务ID的事后成功率或未来行动轨迹。

成功概率p与失败条件下的写入分布G分别估计。G的结果为E/C/B/U/A，联合单步分布为`[p,(1−p)G]`。本批完整尝试直接估计自然联合分布；上一批固定失败输入的反思调用不加入本批拟合。

为检验先平均任务再递推造成的偏差，每个特征模型各比较两种成功模型：无任务差异，以及固定尺度1.5的三点任务随机截距。潜变量取−1/0/1，先验权重为1/6、2/3、1/6；同一任务的潜变量跨条件、跨尝试保持不变。训练在任务层积分，预测新任务先使用总体先验，随后只根据该条轨迹已经发生的尝试更新权重。G在各潜类间共享。该候选刻画成功难度差异，剩余更新异质性由误差检查揭示。

若θ为持续的任务潜变量，两次预算概率按下式计算：

$$V_2(M)=\mathbb E_\theta\left[p_\theta(M)+(1-p_\theta(M))\sum_jG(j\mid M)p_\theta(U(M,j))\right].$$

计算时在每个潜类内递推，最后混合，避免每次失败后重新抽取“新任务”。完整有序窗口使`U`在类型层面确定，全文压缩是否足够仍由新任务误差评价。

## 5. 拟合、选择与后续冻结

六个候选均采用固定ridge=1和每类0.5伪计数，优化器与特征定义在采集前保存。成功模型按整场景留出成功Brier选择，反思更新模型按失败条件写入Brier单独选择。先在每条轨迹内平均已发生的相应尝试，再在场景内平均轨迹，最后等权平均18个场景。联合Brier、对数损失和首轮／两轮成功曲线用于评价组合机制。

对成功与更新分别以各自Brier最小者为参照，计算各候选与其逐场景差值的标准误；差值不超过一个标准误的候选中，依次优先常数、错误退出轮数、有序信息；成功模型同一特征组优先无任务随机截距，更新模型没有任务随机截距。这样可以避免更新预测改善掩盖成功预测退步。所有候选在全部校准任务上重新拟合一次并冻结，选中的p与G组成共同核，后续保留任务预测不再拟合参数。

场景聚类bootstrap20000次，种子2026102502；两个任务、七个条件、各轮尝试随场景整体重采样。首轮C−E、纠正／删除和顺序差均为解释性分析，报告区间及逐场景差异；模型比较的开发分数不作为独立验证成绩。报告A类别及相关结果数量，不把A静默并入无错类。

两次预算只需要初始状态和一次自然更新后状态的成功机制。本批覆盖这些状态。三次及更长预算会进入含两条或更多原生新增反思的状态，需另查覆盖，不能直接把本批系数的外推称为已验证。空历史、未修改的原生起始段落和其他错误类型也在本批范围之外。

## 6. 执行与停止

使用既有GPU0服务及空闲GPU2/3，端口8001/8003/8004；GPU1上的其他任务继续运行。采集前核对三个服务身份，并以同一已保存actor/reflector请求各复放一次，共六次调用，全部计入预算。

本批总上限28000次新调用、14400秒，涵盖副本核对、采集和任何失败请求。未知响应不自动重发；身份、记忆、环境恢复、接口或预算检查失败时记录STOP并停止。原始日志在服务器，公开文件保存协议、清单、参数、摘要和语义标签。实现检查与真实Agent结果分别记录。

完成校准后先报告：共同模型是否优于常数、哪些信息改善成功或更新预测、任务混合是否改善两次预算描述、剩余误差来自哪些状态。随后依据误差和精度固定保留任务的预测协议。系统相关工作比较按作者安排留到实验问题解决后集中进行。
