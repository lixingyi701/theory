# 四次尝试的冻结验证

日期：2026-10-25。设计见[四次预算方案](four-attempt-validation-design-20261025.md)。

本批检验有限窗口理论中的失败更新能否提高预算预测：完整模型推进窗口并对新反思积分，简化模型始终按初始记忆预测。所有真实轨迹都执行原生Reflexion；两者是预测对照。

81个未调用过的加热任务覆盖27个非封存场景。主要样本在正确规则／通用计划两种起点交叉种子2130、2131，共324条轨迹；恢复样本在每景一个固定任务上增加保留、纠正、整条删除，共162条轨迹。总计486条，每条最多四次尝试，成功即停。

主要指标为四次预算Brier的固定起点损失减完整更新损失，先平均任务内条件与种子，再平均场景内任务，最后等权平均27个场景。原参数不重新拟合；134任务留出保持封存。原始条目退出与新反思中的错误内容分别记录。

运行只使用GPU 2、3的剩余显存，保留两卡已有训练。预计约11—12小时，整批上限100000次调用、24小时。GPU 0、1不参与。结束后自动核对接口、动作形式和原生成功事件，计算预定分数，释放本批新增服务。

采样前核对完成：65项离线检查、162项官方环境重置检查和完整矩阵验证均通过。协议摘要为`80f28d46a4519d9c9e76eda644af4334e1d333eadaae22963e771bc86bbb546a`。两个推理副本已就绪，尚未发起本批模型调用；公开冻结后开始采样。
