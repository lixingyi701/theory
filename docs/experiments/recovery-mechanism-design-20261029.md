# 同一父失败的恢复收益与条目退出：下一阶段设计

日期：2026-10-29。阶段校准比较已完成且未采用候选，见[实际结果](stage-calibration-20261029.md)。本页把后续研究围绕恢复收益组织起来。父记录、编辑、接口、精度与有限采集协议现已固定，当前采集见[运行记录](recovery-mechanism-started-20261029.md)。

## 研究对象与已准备数据

中心问题是：同一失败起点纠正或删除目标错误后，成功机会怎样变化，收益能持续多少次尝试，预测这些收益需要保留哪些信息？不以给七维预测器补齐每个阶段的均值作为研究终点。

已有1553条开发记录中，筛选首次从三条通用N反思开始、原生执行失败、新反思被标为E的记录，共70条。按身份摘要每任务选一条，形成51任务、23场景，来源与文件摘要见[父记录清单](../../repro/reflexion-20261025/recovery-mechanism-parents-20261029.json)。没有用后续成功选择父记录；这些任务与原E标签均已用于开发，不作为新任务独立验证。

父失败后的可见窗口为两条通用N和一条原生E。这样追踪的是唯一被标记的目标错误，不会像已有`[E,N,E]`面板那样，处理最新条目后仍留下另一条指定错误。其他文字是否包含未编码错误仍需全文检查。

## 同父、同轮次的记忆干预

在同一第二次尝试编号、同一环境重置规则与配对随机种子下，准备五个条件：

| 条件 | 改变的内容 | 回答的问题 |
|---|---|---|
| 原文保留 | 不编辑原生反思 | 给出共同起点的行为参照 |
| 错误等义改写 | 保留目标错误含义，改动预定全部目标区间 | 检查一般措辞变化，配合纠正解释内容作用 |
| 局部纠正 | 纠正全部目标错误表述，其余内容不变 | 错误规则变为正确规则的总作用 |
| 删去目标命题 | 删除相同目标区间，条目仍在 | 区分移除错误与增加正确说明 |
| 整条删除 | 移除该原生反思 | 衡量内容损失、条目占位和后续退出的共同作用 |

全部保持第二次尝试。前四条件仍有一条原生条目，整条删除为零条，因此原生条目数不再等于轮次减一。原生标记只是研究者记录的来源，不能通过修改一个不可见标记来宣称操纵了Agent的记忆。

纠正与删命题若分别编码为C与U，其完整七维摘要相同，父历史也相同；模型必须给出相同预测。预定比较这两个内容条件，有助于检查摘要是否遗漏有用信息。但前期纠正与删句差异很小，本池未保证足以分辨细小效应；未分辨不等于状态充分。

编辑必须覆盖预定义目标命题的全部重复表达，并核对源区间之外保持不变。原文、等义改写、纠正的长度和模态措辞单独记录，不能在填补长度时加入任务线索。删句和整条删除的长度差是操作的一部分，其差异不直接解释为纯语义或纯退出时间。沿用原生actor、反思函数、三条可见窗口与每次49个决策，不在分析时修复模型命令。

## 目标量、精度与停止选择

主要目标拟定为四次预算的纠正减错误等义改写，以及纠正减整条删除。它们分别对应明确目标错误的恢复收益和两种恢复操作的收益差。最终协议在采集前固定共同主要比较、多项区间、种子与实际样本量，预留完整的保留原文、删句和各预算结果。

以任务内配对种子平均、场景内任务平均、23场景等权计算。精度规划要用已有配对结果的场景差异，给出本池能约束的收益范围；不能因为有大量模型调用就把它当作大量独立场景，也不能承诺能分辨前期约2个百分点的纠正／删除差异。新增种子和新增任务在同一场景内的作用与新增场景不同。若精度不足，先明确本批是机制开发，正式独立验证另行设计。

同时记录三类结果：每个分支的绝对累计成功概率；同父分支的收益曲线；实际错误顺序、加热成功与失败后写回。写回优先报告从共同起点出发的“本次失败且新反思含错”联合事件。给定失败的写错比例可以描述，但不同干预下的剩余失败人群不同，不能单独当作传播强度的因果比较。

## 分开检验后续退出时间

上述五条件估计恢复操作的总效果，不能单独证明条目退出时间造成了差异。若要检验这一机制，可在纠正分支增加一个预定的保留规则对照：开始时均为`[N,N,C]`，失败后都写入相同新反思；正常FIFO与“原纠正条目至少保留到第四次尝试”在前三次尝试看到相同窗口。

连续三次失败后，正常FIFO第四次读取`[J1,J2,J3]`，保留规则读取`[C,J2,J3]`。两者都是三条记忆，使用同一个父任务、共同前三次失败经历和配对第四次种子。这个对照检验以原纠正条目替换最早新反思的后续保留策略，不把J1假定为无作用占位。只需在共同前缀后增加第四次分叉，避免把同一前缀调用重复采集。

该对照需在首个请求前就固定，否则不能在看到前三次结果后临时选择有利轨迹。成功较早的共同前缀没有第四次结果，从初始共同起点计算两策略预算成功差；连续三次失败后的条件效果另报。其结论是指定保留策略的机制证据，随后再检验原生FIFO下的收益预测。该对照现已纳入冻结协议，随共同前缀执行。

## 状态修订的判断依据

若同摘要、同父历史的内容干预建立稳定差异，修改语义摘要；若父失败阶段或任务条件解释剩余偏差，修改预测者的条件化方式；若只在自然轮次协议内有效，将阶段指标保留为预测基线。七维是当前参照，不限制未来需要多少信息。
