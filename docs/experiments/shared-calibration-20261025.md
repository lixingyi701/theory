# 新任务共同机制校准：结果与冻结参数

日期：2026-10-25，计数更正于2026-10-26。36个新任务、18个场景的校准已完成。共同模型在整场景留出比较中改善了成功预测和两次预算预测。事件数与不同文本数的更正见[勘误](shared-calibration-count-correction-20261026.md)，原拟合事件和参数保留。

## 1. 本轮回答了什么

原生语句干预表明，修改目标错误表达会改变首轮成功率和反思输出。本轮进一步采集完整尝试，以及失败后保留原生反思的第二次尝试，用一组共同参数描述七种起始记忆。

结果支持继续沿共同机制建模推进：有无目标错误是当前最强的预测信号，持续的任务难度差异提供较小补充；增加全部正确说明与顺序特征，尚未带来足够的额外预测收益。模型选择按[采集前设计](shared-calibration-design-20261025.md)执行。

## 2. 执行与结果

[采集前提交](https://github.com/lixingyi701/theory/commit/513a93173d14f3ae4f04c836577e7bf0bacdc148)固定了任务分区、执行器、模型与选择规则。252条轨迹全部完成，共463次尝试；首轮成功41条，两次内成功58条。采集耗时8616.02秒，约143.60分钟；19088次请求全部收到响应，累计64027次。原18个保留任务和134任务留出均未调用模型。

同位置C相对E的首轮成功率差为41.67个百分点，场景聚类95%区间[27.78,55.56]；两次预算差为47.22个百分点，区间[27.78,66.67]。这些是校准中的描述性区间。

纠正最新错误与删除最新整条反思的两次成功率差为8.33个百分点，区间[−8.33,25.00]。纠正最新与纠正最旧的差为11.11个百分点，区间[0,22.22]。目前较清楚的是残留错误会限制恢复；纠正／删除和顺序的严格优势仍需新数据分辨。

## 3. 反思如何更新

405次失败均写入一条新反思，对应402种不同文本。按不同文本阅读全文标注，目标前提标签为E286、C13、明确冲突B14、未明确表达目标前提U74、含糊A15；按写入事件计数则为E288、C13、B14、U75、A15。标签按内容摘要复用于重复文本，尚无人工第二复核。

U仅表示未明确表达所追踪的微波炉前提，可以包含替代设备、跳过加热等其他错误。单独的“heat … in microwave”措辞不会自动记为E；E需要明确的器内放置／保持建议或相应前提解释。先取物再放入的顺序记为E；要求加热时仍持有物体、同时保留器内加热建议时记为B；时点或指代不清时保留A。

从[N,C,N]出发的19次首轮失败中，新反思E/C/U/B分别为12/1/4/2；从[N,N,N]出发的18次首轮失败中，E/A/U/C分别为10/2/5/1。这些是起始记忆不含E后生成目标错误的记录。比较它们时需保留各自的失败分母，因为进入失败子集的任务经历也可能不同。

本轮完整尝试提供自然成功与失败更新的联合数据。此前固定失败输入的反思调用，继续用于解释条件更新机制，没有加入本轮拟合。

## 4. 共同模型的预测表现

三组特征分别为常数、错误状态与退出轮数、有序E/C信息扩展；成功侧各比较无任务随机截距和持续随机截距。实际长度、原生条目数和A数量也进入非恒定模型。

成功模型按成功Brier选择，反思更新模型按失败条件写入Brier选择，均采用整场景留一和预定的一个标准误简约规则。最终成功侧选择“错误状态／退出轮数＋持续任务随机截距”，更新侧选择“错误状态／退出轮数”。有序信息扩展的更新Brier略低，但未超出简约选择范围；成功Brier也没有优于选中的较小模型。

| 整场景留出指标，越小越好 | 无任务差异常数 | 选中共同模型 | 改善量及场景95%区间 |
|---|---:|---:|---|
| 联合Brier | 0.62303 | 0.51763 | 0.10540 [0.06862,0.14114] |
| 单次成功Brier | 0.16369 | 0.12202 | 0.04167 [0.02285,0.05998] |
| 两次预算Brier | 0.17892 | 0.14324 | 0.03568 [0.01147,0.05754] |

改用具有相同持续任务随机截距的常数基线，两次预算Brier改善为0.03616，区间[0.01284,0.05779]。后续独立预测以这个基线为主要比较，减少任务差异建模对记忆效果比较的影响。

在相同记忆特征内加入持续任务随机截距，成功Brier改善约0.00138，区间[0.00044,0.00233]。因此，本轮主要预测收益来自记忆状态，任务混合提供较小的附加收益。退出轮数表示整体被选中，其相对错误存在性的独立贡献尚未在本轮单独分离。

上述结果用于校准和模型选择；区间来自参与选择的18个场景。参数已固定，随后在另外九个场景的新任务上评价预测。

## 5. 与理论的对应

本轮把理论中的三个对象接到了实际记录：起点状态对应实际长度与有序反思；p对应一次完整尝试的成功；失败联合转移对应本轮失败及其原生反思写入。有限预算概率仍按同一任务内递推、最后混合的方式计算。

第一，纠正不等于错误已经从窗口消失。[E,N,C]仍有旧E，其首轮表现与整条删除接近；而[N,C,N]没有旧E，表现明显较好。第二，旧E退出也不等于后继窗口不会含E，失败后新生成的反思需要进入转移。第三，持续任务差异改善了预测，符合[任务混合分析](../research/persistent_task_mixture.md)要求在任务内递推的方向。

参数文件保存全部六个候选、选中组合和初始预测。两次预算的冻结预测分别约为：单个E12.20%，匹配C与通用N均49.61%，重复E及最旧C均11.90%，纠正最新E22.73%，删除最新整条反思11.75%。这是接下来要用新任务检验的具体数值。

理论仍提供条件关系与误差分解，实证现在有了共同参数的预测信号。接下来的工作是检查这些固定数值在新任务上是否继续有效。

## 6. 实现检查与下一步

接口审计通过，零空响应、零未确认调用、零意外思考块。7次actor输出达到长度上限，分布在四条轨迹、三个任务中，全部保留。命令形式审计记录84条环境叙述句和266条其他未匹配形式；这些是模型实际输出，不进行语义修补。排除三个受截断影响的整个场景后，保留30任务，C−E首轮差为40.00个百分点、两次差为50.00个百分点，纠正最新／删除两次差为6.67个百分点，主要方向相近；该敏感度不替代全样本结果。

采集后的命令形式审计补上了所需的安装语法路径参数，原始采集记录和冻结执行器保持原样。采集前61项离线检查通过；随后增加了组合模型装配与固定预算评分的检查。闭账文件绑定原始记录、语义标签、事件、参数与成本摘要。

[下一批设计](shared-validation-design-20261025.md)保持原九个保留场景，将每景任务由2补至6，共54个新任务。基于本轮方差估计，配对两次预算Brier差的95%半宽由约0.0385降至约0.0240。独立统计单元仍为九个场景。新增任务按固定顺序选择，参数与预测在调用前保存。

主要验证使用环境成功事件评分，采集后自动计算固定预测误差；反思语义标注用于后续机制诊断。原134任务继续封存，系统相关工作比较留至该验证完成后集中整理。
