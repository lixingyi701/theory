# 固定参数的新任务预测：结果与解释

日期：2026-10-25。接续[共同机制校准](shared-calibration-20261025.md)与[采集前设计](shared-validation-design-20261025.md)。54个新任务、九个保留场景的378条轨迹全部完成，参数没有重新拟合。主要指标支持记忆状态带来的预测改善；更新机制的独立预测收益和纠正相对删除的优势仍需分辨。

## 1. 主要验证结果

使用同一持续任务随机截距的常数模型作主要基线。两次预算Brier从0.18151降至0.14781，改善0.03369，九个配对场景均值的Student t95%区间为[0.01360,0.05379]，达到采集前规定的预测改善标准。相对误差下降18.56%；这里下降的是概率预测损失，不是Agent成功率提高18.56个百分点。

| 预算与指标，越小越好 | 常数＋持续任务差异 | 共同记忆模型 | Brier改善及95%区间 |
|---|---:|---:|---|
| 一次预算，补充指标 | 0.12628 | 0.08949 | 0.03679 [0.01537,0.05821] |
| 两次预算，主要指标 | 0.18151 | 0.14781 | 0.03369 [0.01360,0.05379] |

主要区间按冻结规则使用九个场景、自由度8。场景整体bootstrap的补充区间为[0.01719,0.04893]，方向一致；九个场景中八个的损失差为正，FloorPlan26为−0.01084。实际95%区间半宽0.02009，小于规划时约0.025的目标。

本次验证将校准中约0.03616的预测改善推进到了新任务上的固定参数评价。七种起始条件均在校准中出现过；新任务未参与拟合，九个场景与本次校准的18个场景分离，但在更早开发中出现过。本轮检验的是这个分区下的新任务预测，新的恢复组合和更长预算尚未验证。

## 2. 七种起始记忆的实际表现

条目从旧到新排列。E表示本环境中错误的加热前提“必须先把物体放入微波炉”；C表示ALFWorld文本接口要求的“加热时物体仍在库存”；N为通用任务计划。这里的前提针对该环境的动作接口。N是实际可见的反思条目，不是空槽位。

| 起始记忆 | 首轮成功 | 两次内成功 | 冻结的两次成功概率 |
|---|---:|---:|---:|
| [N,E,N]：中间条目含E | 1/54（1.85%） | 4/54（7.41%） | 12.20% |
| [N,C,N]：同位置改为C | 27/54（50.00%） | 31/54（57.41%） | 49.61% |
| [N,N,N]：不含目标前提 | 23/54（42.59%） | 26/54（48.15%） | 49.61% |
| [E,N,E]：两条含E | 0/54 | 5/54（9.26%） | 11.90% |
| [E,N,C]：纠正最新错误 | 1/54（1.85%） | 10/54（18.52%） | 22.73% |
| [E,N]：删除最新整条反思 | 1/54（1.85%） | 8/54（14.81%） | 11.75% |
| [C,N,E]：纠正最旧错误 | 3/54（5.56%） | 6/54（11.11%） | 11.90% |

最清楚的分离是起始窗口是否仍含目标错误。匹配位置的C与E，两次内成功率相差50.00个百分点，场景t95%区间[29.74,70.26]；N与E相差40.74个百分点，[26.26,55.22]。这些补充对照区间未经多重比较调整。每个条件使用不同固定种子2120至2126，按任务配对；本轮没有交叉轮换条件与种子，文字效应与固定种子差异未在本批单独分离。

正确说明相对N多成功5个任务，差9.26个百分点，区间[−6.58,25.09]。因此，E的有无提供了较强的预测区分，C在无E条件下的额外作用尚未明确；这也与较丰富E/C顺序模型在校准中未获选择优势的结果相符。

[E,N,C]仍保留最旧的E，首轮仅1/54成功；[N,C,N]没有旧E，首轮27/54成功。这个比较说明“写入一条正确说明”与“可见窗口不再含目标错误”对应不同起点，不能将两者合称为已纠正状态。

纠正最新错误相对删除最新整条反思，两次成功率差为3.70个百分点，区间[−12.97,20.38]；冻结模型预测的差值为10.98个百分点。数据没有分辨严格的策略优势。纠正最新与纠正最旧相差7.41个百分点，[−11.93,26.74]，也不足以单独确立位置优势。

## 3. 第二次尝试贡献了什么

首轮共56条轨迹成功，322条进入第二次尝试；第二次新增34条成功，两次内合计90/378。完整采集为700次尝试，其中610次失败后生成了新反思。每条轨迹只在起点实施一次记忆干预，后续使用原生反思追加、三条可见窗口与环境重置。

纠正最新错误组在首轮失败后又成功9/53，条件成功率16.98%，冻结预测为16.75%；删除组又成功7/53，为13.21%，预测为5.68%。单E组又成功3/53，为5.66%，预测为5.67%。这些数值说明部分后继概率与记录接近，也指出删除组的第二轮机会被低估。失败子集随条件变化，不能直接将这些比例差解释为同一批失败经历下的更新因果效应。

主要评分无需反思语义标签。本轮610条新反思尚未逐条标注，所以此处不报告目标错误的生成率、再次表达率或纠正率。后续机制分析需将文本内容与窗口更新记录对应，不能由任务失败直接推断新反思含E。

## 4. 哪些模型成分已获得支持

主要比较保持任务差异建模一致，表明读取记忆状态比忽略记忆状态能更准确地预测新任务的预算成功事件。相同记忆特征但无任务随机截距的冻结模型，两次Brier为0.14773；选中模型为0.14781，差异约−0.00008，95%区间[−0.00069,0.00053]。因此，本轮没有确立持续任务随机截距的额外优势。

为区分起始状态的预测信息和更新机制的额外贡献，采集后增加了一项零拟合诊断：保留原成功系数、同一任务潜变量及其先验，第二次仍按初始记忆计算成功概率，不使用反思更新。这不是实际Agent的执行协议，而是一个省略记忆变化的预测对照。其两次概率为

\[
 \widetilde V_2(M)=\sum_z\pi_z\left[1-(1-p_z(M))^2\right].
\]

该对照Brier为0.14923，完整模型为0.14781；完整更新模型改善0.00141，场景t95%区间[−0.00794,0.01077]。这项探索性比较未显示可分辨的额外收益，不改变预定的主要结果。

两项证据共同界定本轮进展：共同状态模型已经在新任务上优于忽略记忆的基线；当前两次预算仍不足以区分完整反思更新模型和固定初始记忆的预测近似。退出轮数的独立作用也尚未从错误存在性中分离。对每个起始条件，54个任务使用同一个冻结的总体先验概率；本轮没有给每个任务单独估计难度。

## 5. 与理论的对应及下一步

[有限窗口分析](../research/finite_memory_recovery_analysis.md)描述当前成功概率与失败更新核怎样共同决定有限预算成功率；[有序状态分析](../research/recovery_state_sufficiency_analysis.md)区分旧条目退出和后继窗口的语义内容。本轮检验了由校准参数产生的预算预测，提供了新任务上的预测证据。数学命题的条件成立性、每个状态维度的必要性和真实更新核的充分性，需要各自对应的检验。

后续保持当前参数作为已冻结参照，按以下顺序推进：

1. **集中整理方法差异与论文论证。** 现在可以按此前安排比较近邻工作的研究对象、理论假设、干预单位、参数来源和留出方式，将本轮结果放到相关工作中定位。主张围绕有限预算恢复预测及其条件展开。
2. **先用已有记录检查更新误差。** 优先追踪删除组被低估的第二轮成功，以及FloorPlan26的预测差异；对有关新反思作E/C/B/U/A全文标注，保留含糊和冲突类别。分析属于本批诊断，不回填参数后宣称同一批再次验证成功。
3. **为更新机制设计更长预算的冻结检验。** 三条可见窗口需要三次失败更新，原最新条目才会在第四次尝试前完全退出。下一批应包含四次预算，对照原生更新预测与保留初始记忆的近似，并保留纠正／删除轨迹。先检查冻结预测能产生多大可分辨差异，再决定任务数、种子交叉安排和调用预算；不再仅重复相同两次预算矩阵。

本轮不要求立即扩充状态或按策略分别拟合。若已有记录指出了具体缺失变量，修订模型归入新的开发阶段，再留出新的验证分区。原134任务继续封存，启用前另定用途与四场景结构的统计解释。
