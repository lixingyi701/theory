# 七维参数的可兼容性、剖面与条件校准

日期：2026-10-27。上一轮已修正实际长度权重，但不同拟合目标仍在初始、第二轮与晚轮条件间产生折中。本轮区分两个问题：现有七维函数能否表达相近总体风险下的条件成功比例，以及使用开发数据估计出的这类参数能否在整场景留出中保持表现。

## 1. 数据与固定条件

复用1553次尝试、163任务、27场景、760起始轨迹、420成功。保持七项特征、任务尺度1.5、任务先验与偏移、原条件反思模型G及固定起点权重。每条到达尝试的权重为a_b=v_b/4；训练缩放为4×预定起始轨迹数。原冻结参数、结果与134任务留出保持原用途。

五个组预先固定为初始C/N、初始含错、第二轮、晚轮含错、晚轮不含错。这五组在当前数据中划分全部尝试。对组g，条件平均预测偏差定义为：

```math
m_g(\beta)=\frac{\sum_{b,j}a_b I_g(b,j)[q_{bj}(\beta)-Y_{bj}]}{\sum_{b,j}a_b I_g(b,j)}.
```

使用此前推导的包含失败后任务权重变化的∇q，得到∇m_g。风险为固定起点权重下的到达Brier；记J=R+P/K，P为原岭与截距惩罚，K=4×预定轨迹数。

## 2. 条件偏差的不确定性

使用此前混合似然模型的整场景留出概率，保持预测固定。进行20000次重复抽样，种子2026102706：先重采样27个场景，再在每个抽中场景内重采样任务，任务下的分支和种子一起保留。报告五组残差的逐项百分位95%区间，以及按中心化最大标准化偏差构造的同时区间。

这些区间描述已有固定预测的任务／场景抽样变动，不包含重新拟合参数的不确定性，也不把已用于开发的记录重新视为独立验证。后续约束不使用这些区间挑选容许偏差。

## 3. 全数据中的参数可兼容性

比较以下固定情形，每个情形从此前逐轮Brier完整拟合、混合似然完整拟合、零向量三个点开始：

- 五组同时要求|m_g|≤δ，δ分别为0、0.02、0.05。
- δ=0.02时逐一去掉五个组中的一个约束。

共八个情形、24次约束优化。δ=0使用等式，其他情形使用双侧不等式。候选是否满足约束由计算出的实际残差检查，容差为10⁻⁶。若找到可行系数且J不超过此前完整逐轮Brier解加0.001，记录为“找到相近风险的参数见证”。这是一项经验可兼容性检查，不是新预测结果或参数置信集合。

找到见证可以说明这些经验条件在现有七维内并非必然冲突。局部数值搜索失败不能证明不可表达或全局不可行。

## 4. 已有系数的剖面

以此前完整逐轮Brier系数为中心，分别固定原生条目数、含错主项、错误退出距离、含错×已有原生反思四项系数，偏移量为−1、−0.5、+0.5、+1，重新优化其余六项，共16次优化。中心点复用已有拟合。报告风险、五组偏差和其他系数的补偿变化。

另外精确分解q_j=πᵀp_j+(w_j−π)ᵀp_j，报告失败后潜类权重对各组平均预测的贡献。这是模型内部的代数分解，不是Agent因果效应，也不据此直接取消任务差异。

## 5. 固定条件校准方法的场景留出

额外固定一种估计方法：训练集上五组均要求|m_g|≤0.02，最小化相同J。27个整场景留出，每折从此前该训练折的Brier及混合似然系数两个点开始；根据训练J选择收敛且可行的解，共54次优化。约束及拟合不使用留出场景的结果。

主要比较为此前混合似然预测减去约束校准预测的固定起点风险，配对标准误按场景贡献计算。仅当改善大于一个标准误、初始C/N与晚轮含错条件Brier均未增加、所有27折有收敛可行解且完整数据存在0.02可行解时，才保留为后续开发候选。原逐轮Brier为补充参照，不替换主要比较。候选仍需另做冻结预算验证。

## 6. 数值实现与执行范围

共94次优化：24次兼容性、16次系数剖面、54次场景留出。两个CPU进程，优化和重复抽样总计算窗口900秒；准备阶段依赖下载／安装最多240秒，导数检查不超过60秒。不运行Agent或GPU。

使用本轮独立目录中的SciPy1.15.3 [SLSQP](https://docs.scipy.org/doc/scipy-1.15.3/reference/optimize.minimize-slsqp.html)，解析目标梯度与约束Jacobian，最多300次迭代、ftol=10⁻¹¹，系数搜索范围[−30,30]。该版本[支持当前Python与NumPy版本](https://docs.scipy.org/doc/scipy-1.15.3/release/1.15.0-notes.html)；依赖版本及安装包摘要写入协议。原研究环境的NumPy及Agent依赖不作升级。

先核对新目标／约束导数与有限差分、与上一轮目标的一致性及五组划分，再公开[源码](../../scripts/profile_seven_compatibility.py)和协议后运行。数值失败单独记录，保留部分结果，不把缺失折补记为失败任务或全局不可行。
