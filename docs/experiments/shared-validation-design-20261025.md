# 冻结共同参数后的新任务预测

日期：2026-10-25。接续[共同机制校准](shared-calibration-20261025.md)。本批使用固定参数预测新任务在一次、两次尝试内成功的概率。

## 1. 验证问题与固定模型

校准在18个场景、36个任务上完成，原生尝试和更新得到一个共同状态模型。现在检验它在拟合分区之外的新任务上，能否比不读取记忆状态的模型更准确地预测两次预算成功率。

骨干、原作者Reflexion函数、环境、提示模板、动作接口、采样配置和尝试内预算全部沿用校准设置。选中模型的成功部分使用实际窗口长度、原生条目数、含糊条目数、是否有目标错误及其剩余退出轮数，并保留跨轮不变的任务随机截距；失败后的反思更新使用同组记忆特征。系数来自校准后的参数文件，验证期间不重新拟合。

主要基线不使用记忆特征，但采用相同的持续任务随机截距、相同校准任务和尝试预算。这一比较主要评价记忆状态提供的预测信息。另保留无随机截距的常数模型，以及使用记忆特征但无随机截距的模型作补充比较。

所有初始状态的一次／两次成功概率在模型调用前写入协议。计算时在同一任务潜类内递推后再混合；每个新任务的初始预测均使用固定总体先验，不读取该任务的结果。

## 2. 场景分区与样本数

保持原来预留的九个场景，并完整保留其中已选出的18个任务。根据校准阶段的方差估计，将每个场景补至六个新任务，共54个任务；新增任务按原固定哈希顺序选择，排除所有已调用任务及game／trajectory摘要重复项。场景分区和原134任务留出不变，选择不读取新任务的模型结果。

以两次预算Brier差为目标，校准得到的场景间与场景内任务方差估计分别约为0.000213和0.004594。九个场景、每景两个任务时，Student t近似的95%区间半宽约0.0385；每景六个任务时约0.0240。本批以半宽约0.025为精度目标，独立统计单元仍为九个场景。方差估计来自18个校准场景，实际验证精度由新数据决定。

这些场景在更早的开发中出现过，本批检验的是与当前参数拟合分区分离的场景和新任务。七种起始记忆沿用校准矩阵；更长预算、空历史和新的错误类型另行安排。

## 3. 采集

每个任务使用以下七种起始记忆，条目从旧到新排列：`[N,E,N]`、`[N,C,N]`、`[N,N,N]`、`[E,N,E]`、`[E,N,C]`、`[E,N]`、`[C,N,E]`。分别对应单个错误、正确说明、无目标规则、重复错误、纠正最新错误、删除最新整条反思、纠正最旧错误。

54×7=378条轨迹，每条最多两次尝试，成功即停，最多756次完整尝试。各条件分别使用新种子2120至2126；同一任务的七种条件按固定轮换顺序运行。失败后仅执行原生反思追加，再重置环境与对话进入下一次尝试，不重复纠正或删除。

调用前完成108次公开初始观察重置核对。执行复用已经使用的共同校准worker、原生actor与reflector。记录每次请求、响应、环境动作、成功判断、反思全文及完整记忆续接。

## 4. 主要指标与判断

对轨迹i，冻结概率为p̂ᵢ，原生环境给出的两次内成功事件为Yᵢ，Brier损失为`(p̂ᵢ−Yᵢ)²`。主要比较是“相同持续任务差异的常数基线损失，减去选中共同模型损失”，正值表示共同模型预测更准。

先在每个任务内等权平均七个条件，再在每个场景内平均六个任务，最后等权平均九个场景。主要区间采用九个配对场景差值的双侧Student t95%，自由度8、临界值2.306004135。下端大于0表示支持预测改善；区间跨0表示尚未分辨；上端小于0表示基线占优。补充报告以场景整体重采样的20000次bootstrap区间，固定种子2026102503。

一次预算Brier、另外两个固定基线、各条件的预测与实际成功率，以及纠正／删除收益作为补充指标，不替代主要判断。模型参数固定，区间反映新验证场景上的预测损失差异。

主要评分只使用轨迹是否成功，不依赖反思的E/C/B/U/A语义标注。采集结束后自动核对任务身份、每次环境重置与完整记忆链，再由冻结评分器计算结果。新反思全文的标注用于之后的机制诊断。

所有采样结果和输出截断均保留，报告受影响轨迹；相关敏感度分析单列，不按表现重采样任务，也不改变参数或主要分母。

## 5. 执行资源与停止

使用GPU0既有服务与GPU1临时服务，并按作者此前允许利用剩余显存的安排，在GPU2/3满足至少60000MiB空闲显存时部署相同副本。保留所有既有进程；服务只监听服务器本地端口8001至8004。启动前后核对显存、服务身份，并复放同一已保存actor／reflector请求，各卡各一次，共八次，计入预算。

本批上限42000次新调用、21600秒，包含副本检查和失败请求。未知响应不自动重发；身份、接口、恢复或预算异常时保存STOP并停止。完成后执行接口与命令形式审计，使用已安装的ALFWorld语法文件作为显式参数，释放本批GPU1/2/3副本。原134任务不调用模型。
