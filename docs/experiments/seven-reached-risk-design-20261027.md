# 固定起点权重的七维开发比较

日期：2026-10-27。沿用[逐轮目标推导与长度权重诊断](seven-sequential-objectives-20261027.md)，本轮修正实际轨迹长度导致的评分权重问题，继续比较七项输入内的参数估计方式。

## 1. 目标与适用条件

对预定起始轨迹b，设场景数S，所在场景的预定任务数T_s，该任务预定分支数B_t，固定起点权重v_b=1/(S T_s B_t)。共同预定最大预算H=4，用于统一损失单位。模型预测和执行预算均不改变：

```math
R(\beta)=\sum_b\frac{v_b}4\sum_{j=1}^4
I\{b\text{ 到达尝试 }j\}\,\ell(q_{bj}(\beta),Y_{bj}).
```

到达事件取决于此前结果；当前这项损失不再除以整条轨迹最终运行了几次。成功终止或原预算结束后的项没有预测和损失，不补记为失败。

给定到达历史和固定起点，Brier条件期望为(v_b/4)[(q−p)²+p(1−p)]，以真实条件成功率p最小。该结论针对无限制概率函数；共享七系数仍可能在不同状态间产生折中。

为保持拟合时数据项与原惩罚的数值单位，使用K×R作为数据项，其中K=4×预定起始轨迹数，完整数据为3040。K、v_b和H均由预定身份决定，不使用实际尝试总数作为缩放因子。岭惩罚λ=0.01及截距对称半计数项保留。

## 2. 数据与比较对象

完整复用1553次尝试、163任务、27场景、760起始轨迹和420成功。原校准36任务各七分支，后继检查27任务各四分支，完整新任务诊断100任务各四分支；任务身份与分支数量均已在先前协议确定。准备阶段检查来源、完整分支数、连续尝试及成功后终止。历史单次或两次预算分支维持原预算，H=4只统一评分单位。

保持七项输入、任务尺度1.5、任务偏移与先验、条件反思模型G。比较原整任务混合似然、逐轮对数损失、逐轮Brier：原混合似然的27折预测复用前一轮文件，两个新目标采用上述相同权重和缩放。每个训练折以该折的完整预定任务／分支身份计算权重。

## 3. 指标、选择与执行范围

主要开发指标为R的Brier版本，27场景等权；配对标准误按场景贡献计算。另报告初始C/N、初始含错、第二轮、晚轮含错和不含错的固定起点权重条件均值，及复用100主要任务的逐轮成功总数。各分组用同一套完整起点权重，不能因进入某分组而重新计算每个任务的分支数。

两个新增目标中主要风险较低者，只有在相对原混合似然的配对场景改善大于一个标准误、初始C/N与晚轮含错损失均未增加、三个完整拟合初值目标差异小于10⁻⁵时，才保留为后续开发候选。未通过则保留原估计方案，不改挑另一项指标较好的目标。本轮不直接替换历史冻结基线。

两个目标各27个整场景留出加三个完整拟合初值，共60次CPU拟合，两个进程，拟合批次限900秒。原134任务留出不调用，不运行Agent或GPU。

## 4. 梯度、权重检查与证据

复用已核对的逐轮后验梯度，保留其对七系数的依赖。新增检查覆盖两种目标在三个点的有限差分、无惩罚目标与独立逐行评分的一致性，以及把所有轨迹截为首轮后首轮权重及拟合缩放不变。旧源码、旧协议、旧概率与本轮源码／设计的摘要固定于协议，拟合前发布。

预期产物为[执行源码](../../scripts/compare_seven_reached_risk.py)、协议、两组逐条场景留出概率、完整拟合结果、独立复算和结果报告。新旧开发分数采用不同权重，所有方法须在新定义下共同重算；原预算评价及其结论保留。
