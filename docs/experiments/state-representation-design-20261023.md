# 新基础任务上的记忆状态检验与共享机制校准

这轮实验检验一个具体假设：只记录目标错误还会在最近三条记忆中保留多久，是否足以预测下一次尝试的结果，以及失败后的反思内容。上轮纠正后的长反思仍保留其他操作建议，因此本轮先用结构相同的短反思隔离目标规则，再检验记忆占用数量和条目位置。

选择 12 个此前未使用的 ALFWorld train 加热任务，每个任务来自不同房间。排除已有公开清单、服务器尝试身份记录中的任务、游戏与轨迹哈希，以及 134 个封存任务的房间。开发房间可以在不同开发批次出现；今后划分训练与验证任务时，同房间必须整体划分。本轮全部属于开发校准，不占用正式留出集。

## 记忆和配对条件

E 写“加热前必须把物体放入微波炉”；C 将这条规则替换为“加热前必须把物体保留在物品栏”。两者其余文字一致，不含其他具体操作建议。N 是实际写入的通用计划；空记忆没有任何条目。完整英文文本和哈希见协议。这里的错误以固定 ALFWorld `heat ... with ...` 接口为准，其持有前提已有公开动作重放证据。

每个任务使用相同的 seed 2101，运行以下九个起始状态，每个状态执行一次完整作者 Reflexion 尝试。失败后仍由原生 critic 生成反思；不修改 actor、critic、示例、工具转换或模型采样设置。

| 比较目的 | 起始记忆，从旧到新 |
|---|---|
| 目标规则、通用建议与空记忆 | `[E]`、`[C]`、`[N]`、`[]` |
| 三个实际条目与一个条目的区别 | `[N,N,N]` |
| 同样含一个错误、不同位置 | `[E,N,N]`、`[N,N,E]` |
| 同样含一个正确规则、不同位置 | `[C,N,N]`、`[N,N,C]` |

共 108 次尝试、12 个独立基础任务。任务内的九个条件配对，同一任务全部交给同一服务副本，运行顺序按任务轮转。重复 N 是有意构造的控制状态，不冒充自然产生的记忆。N 与 E/C 的文本长度不同，因此它们之间的差异还包含提供具体规则所带来的内容与长度变化；E 对 C 是目标命题替换。

## 状态表示和拟合规则

每次尝试的联合结果为 S（成功），或者失败后新反思的 E、C、U、A。U 表示没有表达目标规则，A 表示含糊或矛盾。成功没有反思更新。Codex 阅读完整反思后按内容哈希标注，A 保留为第五类；本轮不把这些标注称为人工金标准。

比较三个共享的多项逻辑模型，不使用恢复操作名称，也不拟合每个任务自己的参数：

1. 常数模型：仅截距。
2. 剩余保留轮数模型：截距，以及目标错误还需 1、2、3 次失败更新才会移出窗口的指示变量；没有目标错误为参照。
3. 内容、占用和位置模型：截距、实际条目数除以 3，以及从右侧对齐后三个位置各自是否含 E、是否含 C 的六个指示变量。

损失为联合结果的交叉熵总和，非截距系数的 L2 惩罚系数固定为 1，截距各类别加入 0.5 个伪观测。使用确定性 Newton 优化，不搜索正则化强度。全部特征、损失、评分和选择程序在采集前冻结。

逐一留出整个基础任务，使用其余 11 个任务拟合，再对留出任务九个条件评分。主指标为五类 Brier 分数，辅以联合对数损失和成功 Brier 分数。每个任务权重相等，不把任务内条件视为独立任务。按任务重采样 20000 次，seed 固定为 2026102304，计算两个模型评分差异的 95% 区间。

若丰富表示相对剩余轮数表示、相对常数表示的改进区间下界均大于 0，则选择丰富表示；否则，仅在剩余轮数表示相对常数的改进区间下界大于 0 时选择它；其余情况选择常数。小样本和房间异质性仍会限制估计精度；评分相近时不宣布压缩假设成立。

随后在完整校准数据上重新估计三个候选模型，保存全部参数和评分，冻结所选模型对长度 0—3 的全部 E/C/N 组合的单次尝试预测。该冻结是后续前瞻检验的输入，本轮不产生正式跨条件验证成绩。

## 与理论的连接

联合概率可拆成成功概率 `pθ(M)` 与失败条件下的反思分布 `Kθ(·|M,Y=0)`，因此可以检查理论中的错误生成、错误重述以及有限窗口状态压缩假设。观察到 C 与 N 的差异意味着“目标错误不存在”还不足以描述状态；观察到位置差异则提示需要记录条目位置。没有显著差异不证明二者等价。

本轮先隔离目标规则。真实新反思可能同时包含其他操作建议；不能直接把所有 U 当成通用 N，再把短反思模型宣布为完整自然 Reflexion 的多轮模型。下一轮应在冻结参数下，用新起始组合和自然长反思检验预测；若出现系统偏差，再按证据增加状态变量。

## 执行范围

固定 Qwen3-8B BF16、作者 Reflexion、最近三条记忆、49 次 actor 决策、256 输出 token 和已审核的 Qwen 非思考采样配置。复用 GPU0 服务，在空闲 GPU1/2/3 上启动相同副本；每个副本先运行一条已有 actor 请求和一条 critic 请求，八次检查计入本轮。

本轮新增调用上限 6000 次，总执行时限 3 小时，包含副本检查和失败调用；达到任一限额即停止，不自动补发不确定请求。预计约 4500—5500 次调用，实际成本按请求日志结算。此前已结束的 5984 次定向校准单独保留，不重新开放其预算。执行前完成 24 次公开重置检查、离线执行检查，并公开冻结协议和代码；结束后核对每次尝试身份、输入记忆、模型请求、轨迹和全部调用响应。
