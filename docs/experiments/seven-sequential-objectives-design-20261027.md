# 七维模型的逐轮拟合目标：推导与开发比较

日期：2026-10-27。上一轮七维重估减轻晚轮低估，却使第二轮和整体开发损失退化。本轮保持七项输入、任务差异和条件反思模型G，比较不同参数估计目标。问题是：按每条轨迹实际使用的历史与评分权重拟合，能否获得更好的早晚轮折中？

## 1. 逐轮概率及其导数

令第j次尝试的七项特征为x_j，任务潜类为z，偏移a_z、先验π_z固定。单类成功概率为p_jz=σ(x_jᵀβ+a_z)。每条轨迹从原先验开始，仅利用本轨迹此前失败：

```math
u_{jz}=\pi_z\prod_{\ell<j}(1-p_{\ell z}),\qquad
w_{jz}=u_{jz}/\sum_vu_{jv},\qquad q_j=\sum_zw_{jz}p_{jz}.
```

当前模型中，给定记忆的反思类型分布G不随z变化，因此类型项在任务权重归一化时抵消。上式保留原来的预测机制；成功后轨迹终止。

拟合β时，历史失败权重也依赖β，不能只对当前sigmoid求导。记

```math
h_{jz}=\nabla_\beta\log u_{jz}=-\sum_{\ell<j}p_{\ell z}x_\ell,
\qquad \bar h_j=\sum_zw_{jz}h_{jz}.
```

则

```math
\nabla_\beta q_j=\sum_zw_{jz}\left[p_{jz}(1-p_{jz})x_j+
p_{jz}(h_{jz}-\bar h_j)\right].
```

平方损失的导数为2(q_j−y_j)∇q_j；对数损失的导数为(q_j−y_j)∇q_j/[q_j(1−q_j)]。实现以对数权重及成功／失败条件权重计算，避免极小概率时相除。失败后递推h_{j+1,z}=h_{jz}−p_jz x_j。

## 2. 比较对象、数据和权重

复用已冻结参数开发的1553次尝试、163任务、27场景、760轨迹、420成功。完整输入与原场景折叠不变，原680次尝试继续提供受控含错起点及窗口长度变化。

三个估计对象采用相同七项输入、λ=0.01、任务尺度1.5、原偏移及先验、原G：

1. 原整任务混合似然：复用上一轮已保存的27折预测及三个完整拟合结果。
2. 逐轮对数损失：每条轨迹从先验开始，只用自己的先前失败更新。
3. 逐轮Brier：采用相同逐轮概率，直接拟合平方损失。

后两者均按尝试→轨迹→任务→场景平均：若某场景有T_s个任务，任务有B_t条轨迹，轨迹有L_b次到达尝试，则每条记录权重为1/(27 T_s B_t L_b)。训练折用该折自身场景、任务和轨迹数重新归一化。数据目标乘训练尝试数N，保留原非截距岭惩罚和截距对称半计数惩罚。

因此逐轮对数损失对照同时改变训练时潜类信息的聚合与数据权重；它与原混合似然的差别不能归因于某一个因素。Brier与逐轮对数损失的比较则保持这两项一致。不同评分的曲率不同，固定惩罚的相对作用也可能不同，本轮不搜索新的λ。

实际轨迹长度L_b与结果有关。匹配当前评分有助于比较当前指标，并不自动保证估计出不加权总体的真实条件成功概率。有限预算预测仍需单独检验。

## 3. 固定比较及选择规则

两个新增目标分别做27个整场景留出和零、+0.2、−0.2三个完整拟合初值，共60次拟合，两个CPU进程，整批限900秒。复用原混合似然结果，避免重复拟合。未启动Agent或GPU，不使用原134留出。

主要指标为27场景等权的逐轮Brier；补充报告初始C/N、受控初始含错、第二轮、晚轮含错与不含错，以及复用100个主要任务的逐轮预计成功数。

两个新增目标中主要Brier较低者，只有在相对原混合似然的配对场景改善大于一个标准误、初始C/N与晚轮含错损失均未增加，且三个完整拟合初值目标一致时，才作为后续开发候选。若未通过，保留原混合似然估计方案；不事后改挑另一项指标更漂亮的目标。开发候选不自动替换历史冻结基线。
