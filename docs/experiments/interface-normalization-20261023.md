# Qwen 与 ALFWorld 的接口规范化

目前确认的格式问题首先来自模型与工具的适配。Qwen3-8B 的参数量没有改变，修正模板或工具语法后，原有输出就能正常结束或执行。模型规模对规划、事实保持和指令跟随的影响，需要在接口固定后单独比较。

## 已定位的原因

| 层次 | 原因与证据 | 处理 |
|---|---|---|
| 模型输入 | 将面向旧 completion 模型的作者提示直接交给 Qwen，缺少其聊天模板和非思考开关。六条相同反思 query 在 raw 下全部达到 256-token 上限，套用官方非思考模板后全部正常结束 | 固定 tokenizer、单 user 模板与 `enable_thinking=False`，逐字核对实际输入；只套用一次模板 |
| 动作行 | 模型有时输出 `> go …`，上层把 `>` 一起当作命令；同一模板但没有行标记解码的诊断前四个任务均失败 | 解析一个可选的前导 `> `，保留原始响应和解码后 hash |
| 工具语法 | 适配器只识别 `put X in/on Y`，Qwen 输出的 `put X in Y`、`put X on Y` 被当前数据的工具语法拒绝。六个相同环境前缀的重放中，等义的 `move X to Y` 全部执行成功，五个直接触发 native won | 固定三种公开放置写法到同一个工具操作，保留对象、容器和编号 |

工具重放只改变最后一条命令的语法，没有重新请求模型。它解释具体失败原因；修正后的完整任务结果由新的独立运行统计。原 pilot 保留为 24 个任务、成功 14 个、1690 次请求的旧接口记录，完整响应已保存。

## 模型要求与采样选择

[Qwen 官方模型说明](https://huggingface.co/Qwen/Qwen3-8B#best-practices)使用对应聊天模板，并提供显式非思考开关。对非思考模式，官方推荐温度 0.7、top-p 0.8、top-k 20、min-p 0。固定模型的 generation config 还给出 EOS `[151645, 151643]`。

模板和模式属于模型接口契约。推荐采样是需要明确选择的生成配置：作者 Reflexion 的参考配置采用温度 0 起步、短输出后逐次升温，top-p 为 1；Qwen 推荐配置采用固定 0.7 的重采样。两者分别记录为 `author_reflexion` 和 `qwen3_non_thinking_recommended_v1`。作者算法函数、最多六次短输出重试、失败后反思与最近三条记忆规则保留；实际采样温度由选定后端配置决定并进入请求日志。

非思考开关关闭 Qwen 的内部 `<think>` 输出；作者的 `think:` 行和失败后的反思仍按 Agent 算法执行。

先在采样不变的条件下复核工具语法修复，再单独比较推荐采样。模型、任务、环境、动作解码、49 决策、三次尝试和 256 输出 tokens 保持一致。输出上限适用于此处的单行动／短反思任务，并通过逐角色截断统计检查。模型卡针对一般长推理任务的长输出建议不直接替代 Agent 的任务预算。

开发配置选择只使用 dev12：比较三次内完成任务数，再检查原始格式、截断、未确认请求和调用成本。两种配置均完整报告；holdout 不参与选择。选定后保存接口配置及服务源码 hash，再进行新任务分叉和机制校准。

选择规则在推荐采样运行前固定：接口契约检查通过后，优先选择三次内完成任务更多的配置；同分时优先官方推荐配置，调用与 tokens 成本另报。

## 固定的解析边界

规范化只处理表示差异：可选行标记，以及三种 put 写法到 `move X to Y` 的对应。Agent 选择了错误物体、错误位置、错误操作或错误编号，仍按原动作执行并记录结果。多行解释、无效工具名和不完整参数不会被猜测为另一条正确动作。

每次调用保存实际模型输入、完整原始输出、解码器、实际采样参数和 seed；每个环境步骤同时保存原动作、提交命令、公开反馈、done 与 won。分别统计行标记归一化、语法别名、空输出、截断和无效果动作。`Nothing happens.` 也可能来自环境前提不满足，不能统一标为格式错误。

新增语法别名先用相同公开前缀重放验证，并以新接口版本运行；既有结果和检查点保留各自的源码及配置。配置文件为 `configs/reflexion_qwen3_8b_protocol.json`，模型服务为 `scripts/deployment/serve_reflexion_profiles.py`，离线接口审计为 `scripts/audit_reflexion_protocol.py`。服务在每条响应中返回解析后的实际采样参数，避免把配置文件默认值误当作生效值。
