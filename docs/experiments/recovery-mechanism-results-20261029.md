# 原生错误恢复：四次尝试的收益与纠正条目保留

采集日期：2026-10-29至30日；分析日期：2026-10-30。接续[执行协议](recovery-mechanism-execution-20261029.md)和[研究设计](recovery-mechanism-design-20261029.md)。

本轮得到了一项明确的主要结果：**从相同父失败出发，将原生反思中的目标错误改为正确说明，相对保留错误含义的等义改写，使恢复后四次内的成功率提高16.81个百分点，预定调整区间为[4.98,28.64]个百分点。** 纠正相对整条删除的差值为8.48个百分点，区间[−8.73,25.69]，尚未分辨两者在四次预算下的优势。

结果也显示了有限窗口研究值得继续的具体原因：纠正与删除的差距随尝试预算变化；原纠正条目退出窗口时，用它替换最早一条新反思，出现正向的次要对照结果。与此同时，旧七维预测对不同恢复分支的偏差明显不同，仍不能据此声称共享预测机制已验证。当前已完成主要收益、动作和成本分析；新反思的完整语义标注分批继续。

## 1. 这次实际比较了什么

51个任务来自23个场景。每个父尝试都从三条通用计划开始，真实执行失败后生成一条明确包含目标错误的原生反思。这里追踪的错误是：**加热前先把目标物放入微波炉，并在目标物仍在其中时加热。** 本环境相应的加热命令要求目标物由Agent持有。原生反思还可能包含其他设备、命令或原因推测。

从父失败恢复环境与当轮交互历史后，最新三条可见反思为“两条通用计划＋一条原生含错反思”。五种操作只改变这份记忆，保持同一逻辑第二轮、同一环境重置与两个配对种子：

| 操作 | 修改内容 |
|---|---|
| 原文保留 | 保留完整原生反思 |
| 错误等义改写 | 改写目标语句，保留错误含义 |
| 纠正目标命题 | 将所选目标错误改成加热时持有目标物的说明 |
| 删去目标命题 | 删除同一组目标语句，保留该条反思其余文字 |
| 整条删除 | 删除完整新增反思，留下两条通用计划 |

每种操作有102条轨迹，共510条主轨迹。恢复后最多四次新尝试，每次失败正常生成反思，成功则停止。四次预算对应逻辑第二至第五轮，不包括已经发生的父失败。

另有102条“保留原纠正条目”派生策略，与普通纠正共享前三次实际尝试。如果前三次均失败，普通第四次读取三条新反思`[J1,J2,J3]`；保留策略读取`[C,J2,J3]`，其中C是本任务起始纠正后的完整原生条目。49个共同前缀需要新增第四次分支，其余53个前缀已成功，不重复采集。

这些任务及父标签已参与开发，本轮是采集前固定的机制干预开发实验。78处编辑由单个Codex阅读全文后确定；所选句子可能还带有命令或上下文，纠正与改写提示长度差为−14至+4个Qwen词元。因此，本轮估计的是这些具体记忆编辑的效果。其他错误建议仍可能存在，纠正组也没有得到完整正确计划。

## 2. 两项主要收益

主要评价先平均每任务的两个种子，再平均场景内任务，最后对23个场景等权。每项使用配对场景t97.5%区间、自由度22；两项共同主要比较按采集前规定进行Bonferroni调整，控制整体错误率。下表全部以百分点为单位。

| 四次内主要比较 | 成功率差 | 预定97.5%区间 | 结论 |
|---|---:|---:|---|
| 纠正−错误等义改写 | +16.81 | [4.98,28.64] | 支持本批任务上的纠正收益 |
| 纠正−整条删除 | +8.48 | [−8.73,25.69] | 尚未分辨四次预算下的优势 |

纠正与等义改写的102个任务／种子配对中，27对都成功、31对仅纠正成功、12对仅改写成功、32对都失败。对照没有把所有文字变化都当成纠正：原文与错误等义改写的四次差值为−3.33个百分点，次要t95%区间[−13.75,7.08]。这项未分辨结果不能证明两种措辞等效，但为解释具体纠正干预提供了对照。

本轮支持的是“改变错误反思可以提高后续成功机会”。它与完整转移模型能否预测所有恢复分支，是两个需要分别评价的问题。

## 3. 一至四次预算的完整成功曲线

每格为“累计成功条数／102；场景等权成功率”。场景内任务数为1至5个，原始总数与场景等权百分比不能互相替代。

| 策略 | 一次内 | 两次内 | 三次内 | 四次内 |
|---|---:|---:|---:|---:|
| 原文保留 | 21；22.57% | 32；34.53% | 39；42.14% | 41；45.40% |
| 错误等义改写 | 23；27.07% | 32；34.09% | 38；40.98% | 39；42.07% |
| 纠正目标命题 | 34；35.43% | 43；43.95% | 53；54.53% | 58；58.88% |
| 删去目标命题 | 25；26.88% | 37；38.73% | 43；45.07% | 45；47.25% |
| 整条删除 | 10；9.96% | 26；27.86% | 39；41.63% | 48；50.40% |
| 保留原纠正条目 | 34；35.43% | 43；43.95% | 53；54.53% | 67；67.57% |

纠正减整条删除的一至四次收益依次为25.47、16.09、12.90、8.48个百分点。删除后的第一次成功较少，后续尝试逐渐缩小差距；纠正减错误等义改写则依次为8.37、9.86、13.55、16.81个百分点。它们描述了两种不同的收益曲线，不能概括为一个固定“恢复增益”。中间预算是预定次要结果，主要结论仍由四次预算的调整区间决定。

其他预定四次对照均保留：

| 次要比较 | 场景等权差，百分点 | 逐项t95%区间 |
|---|---:|---:|
| 纠正−原文 | +13.48 | [1.40,25.56] |
| 纠正−删去目标命题 | +11.63 | [−2.40,25.66] |
| 删去目标命题−整条删除 | −3.15 | [−19.92,13.62] |
| 错误等义改写−原文 | −3.33 | [−13.75,7.08] |
| 保留原纠正条目−普通纠正 | +8.70 | [3.32,14.07] |

这些区间没有按全部次要比较同时调整。“纠正−删句”的方向提示正确说明值得继续检查，但当前区间仍包含零，尚不能用它确认七维摘要必须增加某个具体语义项。

## 4. 纠正条目退出时发生了什么

普通纠正的前三次累计成功53条，因此49条轨迹到达第四次分叉。普通窗口第四次成功5条，保留原纠正条目后成功14条：4对两边都成功，10对仅保留策略成功，1对仅普通策略成功，34对都失败。两策略在前三次的曲线完全相同，是复用相同采集前缀的设计结果。

从全部102个共同起点评价，保留策略比普通纠正多成功9条；场景等权增益为8.70个百分点，预定次要t95%区间[3.32,14.07]。这为有限窗口中的信息保留提供了直接线索：同样经历前三次失败后，用原纠正条目替换最早新反思，有时仍能改变第四次结果。

该操作同时放回完整纠正条目并移除J1。它衡量的是这次替换的总作用，不能单独分成“正确句的收益”“旧条目的年龄效应”或“移除J1的收益”。完整新反思标注与轨迹核查将帮助解释哪些内容随替换改变。该对照属于次要分析，不能取代尚未确立优势的纠正／整条删除主要比较。

## 5. 旧七维模型预测到了什么、遗漏了什么

使用历史680条开发记录冻结的七维模型，未重拟合，也未使用已经拒绝的阶段指标候选。下表为各预算场景等权成功率，单位为%。

| 策略 | 事先预测：一至四次 | 实际：一至四次 |
|---|---|---|
| 原文保留 | 8.21 / 12.63 / 15.07 / 17.70 | 22.57 / 34.53 / 42.14 / 45.40 |
| 错误等义改写 | 8.21 / 12.63 / 15.07 / 17.70 | 27.07 / 34.09 / 40.98 / 42.07 |
| 纠正目标命题 | 35.92 / 45.02 / 48.26 / 50.33 | 35.43 / 43.95 / 54.53 / 58.88 |
| 删去目标命题 | 35.92 / 45.02 / 48.26 / 50.33 | 26.88 / 38.73 / 45.07 / 47.25 |
| 整条删除 | 44.30 / 53.10 / 56.03 / 57.32 | 9.96 / 27.86 / 41.63 / 50.40 |
| 保留原纠正条目 | 35.92 / 45.02 / 48.26 / 51.08 | 35.43 / 43.95 / 54.53 / 67.57 |

偏差有三种不同形态。

首先，纠正后的前两次总体较接近，第三、四次逐步低估；保留纠正条目的第四次低估更明显。其次，原文和错误等义改写从第一次就被低估，第四次约低估24至28个百分点。再次，整条删除第一次被高估34.34个百分点，之后差距缩小到第四次的6.92个百分点。因此，不能把所有分支的问题都称为“晚轮偏低”，也不能用总预计成功数的抵消描述整体拟合良好。

模型事先预测的四次纠正−改写收益为32.63个百分点，实际为16.81；纠正−整条删除预测为−6.99个百分点，实际点估计为+8.48，但后一实测主要区间包含零。原模型预测的纠正条目保留增益约0.75个百分点，实际次要点估计为8.70。恢复收益的大小、方向和随预算变化，都需要与绝对概率一起核对。

这次数据在固定逻辑第二轮改变了实际可见记忆，特别是整条删除使原生条目数从1变成0，提供了旧数据所缺少的区分。但删除也同时改变内容、长度和占位；这个对照并没有把三个作用进一步拆开。父记录还经过“首次失败且写出明确目标错误”的筛选。旧模型只根据共同通用记忆的失败更新任务难度，并未进一步利用生成这类反思的信息，因此共享任务混合能否适用于这个子群也仍需检查。

本轮把预测失配定位到更具体的恢复条件，尚未给出唯一的修订答案。七维继续作为参照；是否改变状态或任务条件化方式，应由内容和行动证据决定。

## 6. 行动顺序、加热与成本

以下按完整策略的102条轨迹计数。“错误顺序”指实际先把目标物放入微波炉，在未取回持有的情况下执行加热命令；它是行动事件，与新反思是否表达错误分别记录。

| 策略 | 曾成功加热的轨迹 | 曾出现错误顺序的轨迹 | 策略尝试数 | 策略请求数 |
|---|---:|---:|---:|---:|
| 原文保留 | 41 | 69 | 316 | 13,511 |
| 错误等义改写 | 41 | 65 | 315 | 13,322 |
| 纠正目标命题 | 58 | 54 | 278 | 11,274 |
| 删去目标命题 | 46 | 68 | 303 | 12,709 |
| 整条删除 | 49 | 87 | 333 | 13,607 |
| 保留原纠正条目 | 67 | 54 | 278 | 11,106 |

保留策略的成本包含复用的前三次，是“若执行该策略”的成本；不是本批新增成本。它只新增49次第四次尝试、1,945个请求。不同策略成功后停止，实际尝试数和进入后续轮次的人群随策略改变；按已到达失败尝试计算的错误比例不能直接作为共同人群的因果比较。

全部实际采集为1,594次尝试，其中主分支1,545次、派生第四次49次。多数失败记录仍停留在“已拿到目标物但未成功加热”：原文247次、改写246次、纠正205次、删句233次、整条删除258次，派生第四次32次。纠正并未使错误动作彻底消失，删除后也仍有大量错误顺序；两者均不能从记忆编辑直接等同推断。

采集约13小时6分35秒。66,372次请求全部有响应，包含四次副本检查；输入187,060,778、输出2,423,072个词元。19次输出截断全部保留，其中actor 4次、reflector 15次。动作形式统计保留30,454个公开命令形式、1,683个其他未匹配形式、84个观察句式动作及32,775个思考步骤，没有根据任务真值修复模型输出。

## 7. 新反思的语义分析仍在继续

本批共有1,349次失败后写入，对应1,218种不同文本，全部进入固定摘要顺序的全文队列，包括末次失败后不再用于本批行动的新反思。主要收益分析不依赖这些待标注类别。

分析时沿用明确目标错误、明确正确说明、两者冲突、两者均未明确表达、含糊待定的分类。其他设备或任务错误不会自动变成所追踪的微波炉位置错误；“在微波炉加热”也不自动等同于“先放进去再加热”。对明确放入后加热的文字和对含糊设备测试的文字分别保留证据。

首批已阅读全文并保存24种文本的判断和引文，覆盖25次写入；下一条为固定顺序索引24。标注未覆盖全部队列前不报告全批错误回写率。完整后从共同起点计算“本次失败且新反思含目标错误”等联合事件，并重建实际可见窗口。起点无该错误后写出错误称为生成；仍可见时继续表达称为重述；有完整消失再出现证据时才称再次出现。单个Codex已知总体结果后的阅读与自查，不作为独立人工或盲评。

全文阅读进度与可复核判断见[语义进度](../../repro/reflexion-20261025/recovery-mechanism-semantic-progress-20261029.json)。本页的恢复收益、窗口替换效果和动作结果已完成；错误写回路径的完整解释待语义部分补齐。

## 8. 接下来怎样推进

第一，完成全队列语义标注，关联每次开始的可见窗口、新反思和实际动作。优先解释纠正仍失败、整条删除后出现错误顺序，以及49对第四次替换中结果不同的记录；全部队列仍保持覆盖，不按成功筛选标签。

第二，在不改写本轮冻结预测的前提下，区分三类证据：同一摘要下纠正／删句是否需要区分正确说明；相同既有失败后，原纠正条目替换J1究竟改变了哪些信息；按明确错误反思筛选的父任务是否具有旧任务混合未表达的差异。现有次要纠正−删句区间仍跨零，因此当前不立即增加第八项，也不继续已关闭的阶段函数搜索。

第三，用完成的机制诊断决定一个有明确比较对象的模型修订，再固定开发划分、共享父轨迹权重及场景留出方式。评价应同时包含各恢复分支绝对曲线、纠正／删除收益曲线和连续失败后的联合事件。修订后再安排冻结验证，而不是利用本批重新拟合后把同一批称为验证。本轮不启动新GPU采样，134个原留出任务继续封存。

理论与这轮实证的连接已经更具体：记忆编辑产生可测的有限预算收益，条目退出后的替换也会改变后续成功。数学模型仍需说明哪些状态信息足以支持共同参数预测；本轮的分支失配给出了检验这些条件的依据。
