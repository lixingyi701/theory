# 第二轮记忆内容与行动轨迹诊断

日期：2026-10-28。上一轮参数剖面显示，严格对齐组均值损害逐条预测，最稳定的残差是第二轮成功机会高估。本轮读取已有反思和行动记录，区分目标错误标签、其他记忆内容、此前失败经历与当前执行阶段。

## 固定对象

完整1553条开发记录中的441条第二轮尝试全部进入分解。重点全文核查126条第二轮可见记忆不含E/B的记录，以及同任务、相同完整七维特征历史的37个B/E匹配组。匹配组覆盖22任务、99次尝试。筛选依据为时间、记忆标签和特征历史，未按成功结果选择。

原E/C/B/U/A标签保持原记录。不含E/B仅表示未标为该条目标错误，不能据此认为所有文字正确、没有含糊A条目或反思对任务有帮助。

## 内容阅读

去重读取重点记录中全部可见的原生反思，记录五种文字属性：位置／搜索建议、具体操作状态和顺序、命令形式讨论、替代加热方式、环境能力推测。这些属性描述文字内容，不直接标记有用性或因果作用。每项判断保留短证据片段和文本摘要；全文仅在服务器保存。

文字阅读视图省略当前尝试结果与行动，但此前总体结果已知，因此不称为独立盲审。随后核查完整窗口及此前、当前行动，将建议与公开反馈相联系；后续行为一致不直接等于记忆导致行为。

## 行动与概率分解

以原checkpoint的native won为成功标准。取到目标物、加热成功和物体放置均须有对应公开反馈，分别统计未取到目标、取到但未加热、加热后仍未完成以及成功。另记录非思考动作的无效果反馈、重复无效果动作、未匹配命令形式，以及“目标放入微波炉后，未再次取出便发出加热命令”的可观察序列。

原作者执行器先将think行交给环境，再将返回给Agent的观察改为OK；不能把checkpoint中这些行的Nothing happens计入物理操作失败。无效果反馈也不能一概解释为格式错误。

固定此前混合似然场景留出概率，按相同固定起点权重，在来源任务组、场景、任务、反思标签和前次执行阶段中分解残差。当前动作和结果用于解释误差，不能当作尝试开始时已经知道的预测输入。

## 执行与产物

本轮新增Agent调用、GPU任务和参数拟合均为零，机器读取和聚合限600秒。复用原采集结果、任务身份、记忆摘要及checkpoint，核对逐条hash和成功链。先固定清单与协议，再开展文字标注和汇总。

保留[诊断源码](../../scripts/diagnose_second_attempt.py)、清单、内容标签、逐条轨迹特征、聚合结果和独立核对。旧参数、原主要预算评分、原始标签及134任务留出保持原用途。根据本轮定位到的信息，再决定对现有七维函数或共享机制做何种比较。
