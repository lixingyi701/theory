# 正确说明的独立作用：最小同状态诊断

日期：2026-10-24。依据[研究调整](../research/review-response-and-research-adjustment-20261024.md)与[状态条件和收益分解](../research/recovery_state_sufficiency_analysis.md)，在新调用前冻结本方案、执行代码和逐条件预测。

## 科学问题与比较

错误存在性模型把不含 E 的 C、N 与空历史合并，也把含 E 的 `[E,N,C]` 与 `[E,N,N]` 合并。本批检查这些合并是否遗漏可重复的单次成功或失败写回差异。保留原错误存在性预测作为冻结基线，所有新参数拟合留到后续阶段。

12 个既定开发加热任务，各使用三个未在这些任务运行过的新种子 2104、2105、2106。每个任务×种子有五种起点：C=`[C]`，N=`[N]`，empty=`[]`，EC=`[E,N,C]`，EN=`[E,N,N]`。共 180 次新的完整单次尝试，不复用旧成功记录。任务环境与 actor 当次历史重置相同，失败后保存一条原生反思，随后终止本格。三条窗口规则与原 actor／reflector 保持一致。

E/C/N 逐字复用既有协议。C 是正确加热前提，N 是真实的一句通用计划，不是无作用的空位。C 与 N 的对比包含其具体措辞和长度差异。本批不把这种比较泛化为任意正确信息，不用动作结果或隐藏标签作输入。

主要估计量为 `p(EC)−p(EN)`：固定旧 E、条目数和槽位，检验最新 C 的增量。次要对比为 C−N、N−empty、C−empty。EC−EN 不是顺序效应；顺序需要后续配套位置对照。

## 执行与冻结

固定作者 Reflexion、Qwen3-8B BF16、既定非思考模板与推荐采样、49 次 actor 决策、最大输出 256 tokens。12 个任务仍各自绑定一个工作进程，任务内种子／条件顺序按预定轮转安排；每个进程使用单 GPU 服务。使用 GPU0 的既有服务，并在空闲 GPU1/2/3 上启动同配置副本，端口为 8001—8004。采集前，每副本各重放一个既有 actor 和 reflector 请求，共八次计费检查；同种子文本核对通过后运行。

本批新上限为 **10500 次请求、10800 秒**，包含副本检查、失败与明确重发；所有旧额度保持关闭。此前累计 34591 次请求均有响应。保存逐请求身份、输入、响应、提交动作、checkpoint、结果和预算占用；未确认请求不自动重试。服务未就绪、身份变化或状态恢复不一致时停止依赖采集。

执行前保存：父协议与标签哈希、任务与初始观察身份、全部起始文字哈希、180 个格的顺序与分配、预测与统计定义、关键代码和设计哈希。134 个 holdout 的模型调用保持零。

## 分析

成功以原生环境 won 判断。先在每任务内平均三个种子的配对差，再等权平均 12 个任务；主区间按完整任务聚类重采样 20000 次，seed 2026102403。另报告每种子结果与成对的任务内种子重采样敏感性分析。后者保持同一任务／种子下五个条件成组，不增加独立任务数。任务是既定开发样本，这些区间不自动支持广泛场景总体。

分别报告成功 S、失败后反思 E/C/U/A 的联合频数与原冻结联合／成功 Brier。失败条件 E 比例仅作过程描述，比较它时必须考虑各条件失败任务不同。原始动作尝试、环境接受及成功分开统计。新反思按全文和哈希标注；旧哈希标签原样复用，含糊与矛盾保留 A，暂无人工二次标注则如实说明。

本批为机制诊断，没有以观察结果调整样本量或训练新模型。主区间排除零时可作为本批 C 增量的证据；包含零时未定，不能宣布状态等价。全部失败或成功导致经验区间退化时，不能据此把真实概率或差值固定为零。一项辅助分数改善不构成模型充分性或校准已成立。

## 结果怎样决定后续

- EC−EN 的成功或联合写回差异支持进一步在任务内复核 C，而不立即按恢复操作另拟参数。
- C−N 与 N−empty 分别定位正确规则与非空提示的作用。两者可能影响不同过程。
- 若本批仍不能分辨 C 的作用，保留结果和区间，先判断是否出现地板效应、任务内不一致或统计精度不足，再决定是否需要更有区分力的新任务；不直接扩大整个多轮矩阵。
- E/C 顺序、固定失败轨迹下的 critic 干预、新任务共享参数校准均另行提出明确比较，不从本批额度追加。

调用结束后核对请求总账、协议、动作形式、语义覆盖和任务配对，发布实际成本与结果。系统相关工作重述按作者安排另留阶段。
