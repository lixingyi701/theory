# 正确规则、通用计划与空记忆：定向诊断结果

日期：2026-10-24。接续[研究调整](../research/review-response-and-research-adjustment-20261024.md)与[有序窗口的状态条件和收益分解](../research/recovery_state_sufficiency_analysis.md)。[设计与执行代码](correctness-diagnostic-design-20261024.md)在采集前随提交 [`c042ebb`](https://github.com/lixingyi701/theory/commit/c042ebb886e9b68f68ed6665db30bac5fb1694d4)冻结。

## 1. 本轮回答了什么

180 次新尝试已经完成。含错误的三条记忆中，将最新通用计划换成正确规则，成功从 2/36 变为 3/36，主要对比尚未分辨稳定的正确规则收益。不含目标错误的三种起点中，正确规则和空记忆都成功 21/36，通用计划成功 13/36。这说明后续应先区分实际输入结构与具体文字，不能直接给模型增加一个统一的“正确规则收益”参数。

本轮保留理论研究问题：一次纠正或删除之后，哪些状态信息足以支持有限预算成功率的递推？新结果用于检查单次成功与失败写回的状态假设，没有重新估计多轮模型。原冻结预测、理论证明与此前的负结果均保留。

## 2. 实际比较与输入核对

使用既定的 12 个开发加热任务，新增种子 2104、2105、2106；每个任务和种子比较五种起始记忆。每格执行一次原生 Reflexion 尝试；失败时保存一条原生反思，然后终止该格。环境和当次行动历史按相同任务、种子重置，权重冻结。固定作者 actor／reflector、Qwen3-8B BF16、非思考模板与推荐采样、最多 49 次 actor 决策及 256 tokens 的输出上限。

三种条目的原文为：

```text
E: Plan: Before I heat an object with the microwave, I must put it inside the microwave. I should continue working on the household task.
C: Plan: Before I heat an object with the microwave, I must keep it in my inventory. I should continue working on the household task.
N: Plan: I should continue working on the household task.
```

C、E 都保留了 N 的通用计划句。C 与 N 的比较增加了具体正确规则，也增加了输入长度。E 的问题是要求先将物体放入微波炉；该环境的加热宏要求物体仍在 inventory 中。

| 条件 | 起始记忆 | 与相应对照的关系 |
|---|---|---|
| C | `[C]` | 相对 N，在同一条目中增加正确规则 |
| N | `[N]` | 一条通用计划；与空记忆的实际提示结构不同 |
| empty | `[]` | 不渲染任务记忆段落 |
| EC | `[E,N,C]` | 相对 EN，仅替换最新条目的文字 |
| EN | `[E,N,N]` | 与 EC 的旧错误、条目数量和槽位相同 |

作者的 [`EnvironmentHistory`](../../third_party/reflexion/env_history.py) 对非空记忆加入如下文字，空记忆则整段省略：

```text
Your memory for the task below:
Trial 0:
<第一条记忆>
```

采集后的[输入核对](../../repro/reflexion-20261024/correctness-diagnostic-input-rendering.json)逐一读取 36 个任务／种子组合的首个 actor 请求，共完成 108 项替换比较：删除 N 的完整记忆段落后，请求与 empty 完全一致；C 替换为 N 后，请求与 N 完全一致；EC 的最新 C 替换为 N 后，请求与 EN 完全一致。比较包含采样字段。核对没有调用模型，也没有修改渲染器。

因此，N−empty 估计的是“标题、条目编号及这句通用计划”这一整段输入的总效果，当前无法分开归因。EC−EN 则固定了非空提示结构。本轮没有交换 E/C 的位置，所以不估计顺序作用。

## 3. 成功率与配对差值

每条件有 36 格；统计时先在每个任务内平均三个种子，再等权平均 12 个任务。主区间按完整任务聚类 bootstrap 20000 次，seed 为 2026102403。敏感性分析在重采样任务后，成组重采样任务内配对种子。新种子增加任务内重复，不将独立基础任务数从 12 计为 36。

| 条件 | 成功／尝试 | 成功率 |
|---|---:|---:|
| C | 21/36 | 58.33% |
| N | 13/36 | 36.11% |
| empty | 21/36 | 58.33% |
| EC | 3/36 | 8.33% |
| EN | 2/36 | 5.56% |

下表单位均为百分点，后一个条件为对照。

| 对比 | 平均差 | 任务聚类 95% 区间 | 配对种子敏感性 95% 区间 |
|---|---:|---:|---:|
| **EC−EN，主要对比** | **+2.78** | **[−5.56, +11.11]** | **[−8.33, +16.67]** |
| C−N | +22.22 | [−2.78, +50.00] | [−5.56, +52.78] |
| N−empty | −22.22 | [−41.67, −2.78] | [−44.44, 0.00] |
| C−empty | 0.00 | [−19.44, +19.44] | [−22.22, +22.22] |

主要对比的 36 对记录中，32 对均失败、1 对均成功、2 对仅 EC 成功、1 对仅 EN 成功。成功较少限制了对机制差异的分辨；区间包含零，不能据此给 C 指定正收益，也不能认定 EC 与 EN 等价。

C−N 的三个种子差值分别为 +25.00、+33.33、+8.33 个百分点，但任务差异使聚类区间仍跨零。N−empty 三个种子均为负；这是本轮较清楚的诊断信号。不过它属于未作多重比较调整的次要对比，种子敏感性区间达到零，应按固定输入条件下的现象解释。

C 与 empty 的成功总数相同，仍有 4 对仅 C 成功、4 对仅 empty 成功。两者的具体路径与受益任务不同，平均值相同不表示作用相同。此前种子 2103 中 C 为 8/12、空记忆为 5/12；本轮新种子没有复现该平均优势，不将旧结果并入本轮作为独立确认。

## 4. 失败后写入了什么

S 为任务成功；E 为失败后新反思明确包含目标错误；C 为失败后新反思明确说明正确前提；U 为未明确表达两者；A 为含糊或冲突。下表是一次尝试的联合频数，行和均为 36。

| 起点 | S | 失败并写 E | 失败并写 C | 失败并写 U | 失败并写 A |
|---|---:|---:|---:|---:|---:|
| C | 21 | 6 | 1 | 7 | 1 |
| N | 13 | 6 | 0 | 15 | 2 |
| empty | 21 | 4 | 0 | 11 | 0 |
| EC | 3 | 19 | 1 | 11 | 2 |
| EN | 2 | 21 | 0 | 11 | 2 |

起点 C/N/empty 均没有目标错误 E；之后写出 E 时称为“生成目标错误”。EC/EN 起点已含 E，其新反思写出 E 时称为“重述目标错误”。本轮没有后续尝试，不能用这些频数计算纠正能持续几轮。

C 与 N 的“失败并写 E”均为 6/36，但在各自失败样本中所占比例为 6/15 和 6/23。条件比例不同，部分来自成功后停止导致的失败样本选择，不能单凭 40% 对 26.09% 宣称 C 增强了错误生成。EC/EN 的对应联合频数为 19/36 和 21/36，下一次递推还取决于新反思的全文以及保留下来的其他条目。

120 条新文本完成 Codex 全文语义标注，旧哈希标签复用，含糊／矛盾保留 A；没有人工二次复核。主成功统计来自环境 won，不依赖这些语义标签。

## 5. 行动轨迹给出的线索

逐步日志核对表明，N 与空记忆的差异不都发生在同一环节。例如，Apple→SideTable、种子 2104 中，N 分支将苹果放入微波炉，随后多次加热无效；空记忆分支持有苹果完成加热，前往 SideTable 后放置成功。Egg→DiningTable、同一种子中，两分支都出现有效加热，但 N 后续的放置没有被环境接受，空记忆分支则完成前往目的地和放置。

这些路径分别涉及加热前提和后续任务完成，不能用一个“错误采用率”概括所有失败。它们提供下一轮干预要区分的具体环节，但没有单独识别记忆标题、通用句或其他文本成分的因果作用。

动作审计共记录 6462 次环境步骤，其中 thought 3216 次、公开命令形式 3115 次、其余未匹配形式 79 次、环境描述句 52 次。物理动作无效 927 次；无效结果还可能来自实体、位置或前提，不直接归为语法错误。事件计数包含同轨迹的重复动作，不作为独立实验样本。

## 6. 冻结预测表现

本轮没有拟合参数。旧常数模型和错误存在性模型逐格使用预先保存的概率，分数越小越好。

| 模型 | 五类联合 Brier | 联合 log loss | 成功 Brier |
|---|---:|---:|---:|
| 原冻结常数 | 0.7135 | 1.3059 | 0.2284 |
| 原冻结错误存在性 | 0.6235 | 1.1510 | 0.1781 |

总体分数改善与某些压缩条件失配可以同时发生。存在性模型给不含 E 的起点相同成功概率，约为 0.571；C/empty 实测均为 0.583，而 N 为 0.361。含 E 的预测约为 0.083，EC/EN 实测分别为 0.083/0.056。该汇总支持保留存在性模型作基线，同时要求对同一压缩状态内的具体条件单独核查；它不等于状态充分性、概率校准或多轮预测已经通过验证。

## 7. 对理论和下一阶段的调整

[本轮理论分析](../research/recovery_state_sufficiency_analysis.md)已给出压缩充分条件及窗口更新反例、一般两次预算收益分解、任务混合关系和预测误差传播界。实验对应的调整如下。

1. **完整过程保留实际窗口。** 继续记录实际条目数和有序序列，由其确定 FIFO 更新；对概率核是否可进一步压缩另作检验。N 与空记忆有不同的实际提示结构，不能在实现或推导中当作同一个输入。
2. **暂不增加统一的 C 收益或 N 惩罚。** 主要 EC−EN 对比未确立 C 的增量；C−N 与 C−empty 也不支持一个跨起点通用的正收益参数。保留原 e/r 基线，候选特征须有明确的条件和新数据检验。
3. **下一定向比较固定非空记忆结构。** 从已保存的原生失败反思中，按采集前规则选择具备明确目标命题的条目；固定其他句子、条目数和槽位，仅保留错误命题、改为正确命题或删去目标句。它检查全文到 E/C/U 类型的压缩究竟遗漏什么，同时避免把整条删除带来的标题和其他信息变化归于目标命题。若需单独归因 N−empty，可再设计空白条目这一明确标注的提示结构消融，不将其称为真实中性反思。
4. **反思写回另按固定失败输入检查。** 当前不同起点产生不同失败路径，失败条件 E 比例混合了路径选择与 reflector 的反应。固定一条失败轨迹和反馈、仅改变记忆中的目标句，才能更直接检验失败写回对它的依赖。先利用现有日志确定输入，再冻结必要的最小调用矩阵。
5. **随后校准与独立预测。** 限定候选状态和共享方式后，先按预定任务分区校准 p 与失败联合核 Q，估计达到所需精度的任务数，再冻结新任务和多轮预测。不得按恢复操作分别重拟合曲线。134 个 holdout 仍未调用，其四场景结构和用途在启用前确定。

这一步的产出是缩小机制假设，而非继续扩充无条件多轮矩阵。主要研究问题和理论递推保持一致：起始记忆如何改变首轮成功、失败写入分布以及下一轮的剩余信息。相关工作的方法差别按作者安排，在当前实验问题解决后集中分析并写入论文。
