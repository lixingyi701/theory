# 七维逐轮目标比较与轨迹长度加权的影响

日期：2026-10-27。本轮完成60次CPU拟合。逐轮目标降低了整体开发分数，但初始C/N与晚轮含错组同时退化，没有采用新参数。进一步推导与复算定位到一个具体问题：用实际轨迹长度平均单次损失，会使评分权重依赖当前及后续结果，因而不适合直接选择条件成功概率模型。

## 1. 固定设计与执行

本轮沿用[上一轮参数开发](seven-parameter-development-20261027.md)的1553次尝试、163任务、27场景、760轨迹和420成功。七项输入、λ=0.01、任务尺度1.5、任务先验、偏移与反思模型G固定。

[推导和比较设计](seven-sequential-objectives-design-20261027.md)、源码及协议在提交[`fc74eb6`](https://github.com/lixingyi701/theory/commit/fc74eb6e3527541b4d894e79e0cfd809c5c21b3e)先行发布。新增逐轮对数损失、逐轮Brier两种估计目标，各做27折整场景留出及三个完整拟合初值，共60次拟合，两个CPU进程约5.47秒完成。原混合似然的已保存预测直接复用。

解析梯度包括此前失败导致的任务权重变化。六个有限差分检查的最大误差为2.30×10⁻⁸，逐条概率与原预测器差异至多1.12×10⁻¹⁶；偏移为零时退化为普通七维评分的检查通过。完整拟合三个初值目标值差异均小于3.4×10⁻¹²。45个保护文件保持原字节。

## 3. 实际长度为何改变评分偏好的概率

此前单次开发分数先对每条轨迹的到达尝试取均值。设轨迹实际长度为L，则其中每次尝试的权重含1/L。首轮成功会立即终止，L=1；首轮失败通常继续尝试，L往往大于1。因此，初始记忆相同的成功与失败记录，首轮权重并不相同。

对同一初始状态，先暂时独立优化首轮常数预测q。设v为由场景、任务和预定分支数决定的固定权重，Y为首轮是否成功。该部分平方损失为

```math
R(q)=\mathbb E\left[\frac vL(q-Y)^2\right],\qquad
q^\dagger=\frac{\mathbb E[vY/L]}{\mathbb E[v/L]}.
```

成功时L=1，而失败时1/L≤1。只要一部分失败轨迹继续运行，这一加权目标就会比固定起点权重下的成功比例更偏向成功。若同一状态内v相同、成功概率为p，而失败轨迹均长H，则

```math
q^\dagger=\frac p{p+(1-p)/H},
```

通常大于p。逐轮对数损失在这个常数预测问题中也有相同的最优加权比例。

这不是数值优化错误，而是评分目标本身赋予不同结果不同权重。Brier作为条件概率评分的性质要求权重不依赖当前待预测结果；先用整条轨迹的实际长度平均，不满足这一条件。

## 4. 数据中的对应关系

580条初始C/N记录共享同一七维向量[1,1,0,0,0,0,0]，首轮成功313次。沿用本轮训练中由场景、任务和分支数确定的固定起点权重：

| 量 | 复算值 |
|---|---:|
| 固定起点权重下的首轮成功比例 | 50.90% |
| 再除以实际长度后，首轮平方损失偏好的常数预测 | 76.66% |
| 首轮成功轨迹的平均实际长度 | 1.00 |
| 首轮失败轨迹的平均实际长度 | 3.32 |

50.90%采用上述固定起点权重，因此不同于直接计算313/580。76.66%是仅对首轮C/N部分独立求得的评分最优点，不是新的真实成功率估计，也不是整个七系数联合目标的最优解。它与本轮首轮过高、晚轮过低的变化相一致，提供了可推导且能从日志核对的解释。

## 5. 对原结果与下一步建模的影响

原四次预算主要评价每条起始轨迹在预算内是否成功，每条轨迹只有一个二元结果，没有除以实际尝试次数。因此，本节的问题不改变该验证的评分或原结论。它影响的是单次成功函数的开发选择：过去按实际轨迹长度平均得到的开发改善，不能单独说明条件成功概率估计更准确。原六维／七维比较的这一开发依据也应在后续一致权重下重新核查；当前按用户确定的方向继续研究七维，不自动增减输入项。

下一步采用由任务与预定分支数确定的起点权重v_b，并用共同的预定最大预算H=4归一化：

```math
R_{\rm reached}(\beta)=\frac1H\sum_bv_b\sum_{j=1}^{H}
\mathbf1\{b\text{ 到达第 }j\text{ 次尝试}\}\,
\ell(q_{bj}(\beta),Y_{bj}).
```

到达第j次尝试由此前结果决定，当前这一项的权重不再使用此后实际还运行几次。停止后的项不产生预测或损失，不把它们补记为失败。单次或两次预算的既有分支在其原预算处结束，H仅为共同单位，不增加尝试。

以平方损失为例，给定到达历史，条件期望可分解为固定权重乘以[(q−p)²+p(1−p)]，因此在无限制概率函数下以真实条件成功率p最小。七维参数共享仍可能导致不同状态间的折中，修正权重不保证模型立即拟合全部条件。

后续应先固定这一新开发目标与选择规则，再使用相同七项输入比较逐轮对数损失、逐轮Brier及当前混合似然。报告首轮、第二轮、晚轮含错和总体到达尝试损失，并保留原轨迹平均分数作为历史诊断。改变目标的理由是上面的推导与实测权重效应，原冻结评价不作回填。

本轮60次拟合已完成，未追加拟合或GPU采样。原冻结参数仍为当前基线，134个留出任务继续封存。
