# 有序反思窗口的状态条件与两次预算恢复收益

更新：2026-10-24。本文将[审核回应](review-response-and-research-adjustment-20261024.md)中的分析整理为后续实验的理论依据，接续[有限窗口主分析](finite_memory_recovery_analysis.md)。下列等式与界是模型内推导；真实 Agent 是否满足其条件，由单独的干预实验检查。

## 1. 过程与概率对象

固定任务 T、环境重置、Agent 提示及采样协议。一次尝试以可见有序记忆 M 开始；成功 Y=1 时停止，失败时生成一条反思 J，并更新为 `last_W(M || J)`。当前协议 W=3。空历史与实际通用计划 N 是不同输入。C 表达正确加热前提，E 表达目标错误前提；这些标签不代表整条反思的全部语义。

定义首轮成功概率 p(M,T)，以及失败并进入完整后继状态的次随机核 Q(M,M'|T)。如控制器保留尝试序号等信息，应将它纳入状态；不能把完整状态中仍有作用的历史默认为已消失。有限预算递推为

$$V_0=0,\qquad V_b(M,T)=p(M,T)+\sum_{M'}Q(M,M'\mid T)V_{b-1}(M',T).$$

本轮恢复只在起点实施一次。纠正一个命题与删除整条反思会改变不同的信息和对齐，后续仍执行原生失败更新。

## 2. 命题一：状态压缩的充分条件与窗口更新闭合

**命题。** 固定 T，令 z=φ(M)。若任意 φ(M)=φ(N)=z 都满足相同成功概率，且对每个压缩后继 z'，

$$p(M,T)=\bar p(z,T),\qquad
\sum_{\phi(M')=z'}Q(M,M'\mid T)=\bar Q(z,z'\mid T),$$

则所有预算 b 的成功概率都只依赖 z，且服从以 p̄、Q̄ 为核的递推。

**证明。** b=0 时均为零。若 b−1 的值只依赖后继压缩状态，将完整后继状态按 z' 分组，代入上式，即得 b 的递推。归纳完成。该条件是充分条件，有限几个预算的成功概率相同不反过来证明整个条件。□

将窗口压为“错误剩余退出轮数 r、是否有 C、C/E 相对顺序”，仍不一定能确定更新。例如 `[C,N,E]` 与 `[N,C,E]` 均有 r=3、有 C，且 C 在 E 之前；追加 N 后分别成为 `[N,E,N]` 和 `[C,E,N]`。若 C 有作用，两个起点的后继压缩状态不同。

因此，程序保留实际长度和有序类型序列，再从中计算特征。给定新条目类型后，FIFO 类型更新是确定的；但这不保证全文到类型的压缩满足上面的概率条件。只有最后一个“错误存在性”影响成功与更新时，已有 r 压缩才是相应二值窗口子模型的精确压缩。

保留窗口结构不等于逐窗口拟合自由概率。参数可按少量机制特征共享，分别检验成功模型和失败更新模型是否需要 C 或顺序。

## 3. 命题二：一般两次预算的收益分解

令纠正和删除后的起点为 M_C、M_D。对 o∈{C,D}，记首轮成功概率为 p_o；q_o(j) 为“首轮失败并写出反思 j”的联合概率；g_o(j) 为追加 j 后下一次的成功概率。若还有续行控制信息，应与 j 一并作为后继变量。

**命题。**

$$\Delta_2=V_2(M_C)-V_2(M_D)
=(p_C-p_D)+\sum_j[q_C(j)-q_D(j)]g_D(j)
+\sum_jq_C(j)[g_C(j)-g_D(j)].$$

**证明。** 对首轮成功／失败条件分解，有 V₂(M_o)=p_o+Σ_jq_o(j)g_o(j)。相减后加减 Σ_jq_C(j)g_D(j) 即得。连续变量用积分替代求和。□

这些项分别对应首轮成功、写入分布及同一新增内容在剩余窗口中的作用。它们不是自动可识别的自然直接／间接因果效应；跨分支缺少某种反思时，对应项也可能没有数据支持。

对 `[E,N,E]` 起点，纠正最新 E 得 `[E,N,C]`，删除得 `[E,N]`。在二者首轮和新增反思机制相同、后继成功只依赖有无 E 的特例中，令 a 为首轮失败且新反思不含 E 的联合概率，可约化为

$$\Delta_2=a(p_0-p_1).$$

因为只有新反思不含 E 时，纠正组的旧 E 提前退出而删除组仍保留它。正收益需要 a>0 且 p₀>p₁。原候选已经包含错误重述；当前需要检查共同的 a、p₀、p₁ 及其状态假设。

本轮最小实验首先检查两个必要的压缩问题：`[C]` 是否可与 `[N]`、空历史共用成功和更新机制；`[E,N,C]` 是否可与 `[E,N,N]` 共用机制。后一比较固定旧 E、窗口长度及位置，识别最新 C 的增量，本身不识别顺序作用。

## 4. 命题三：任务混合对收益的影响

若上述特例在各任务内成立，记 d_T=p₀,T−p₁,T，则

$$\mathbb E_T\Delta_{2,T}=\mathbb E_T[a_Td_T]
=\mathbb E_T[a_T]\mathbb E_T[d_T]+\operatorname{Cov}_T(a_T,d_T).$$

**证明。** 逐任务应用特例，再用协方差定义展开。□

相乘总体平均参数可能遗漏协方差；当前数据尚未识别其大小。一般多轮总体为 `1−E_T[e_M^T Q_T^b 1]`，一般不等于先平均核再递推。任务内单独拟合可用于定位异质性，但新任务预测不能读取事后估出的 task ID 参数。

## 5. 命题四：近似状态误差对预算与排序的影响

令成功为吸收态，真实与近似单步核在全部将到达的对应历史上，条件总变差均不超过 ε。通过每步最大耦合，未分离条件下每步分离概率至多 ε，故

$$|V_b-\widehat V_b|\le1-(1-\varepsilon)^b\le b\varepsilon.$$

两个恢复起点分别有误差界 η_C、η_D 时，由三角不等式，收益预测误差不超过 η_C+η_D。预测收益差超过该范围才足以保证排序。小样本 Brier 改善不能估计上述统一界。

这个结果约束模型修订：以关心的预算和容差决定是否需要新增变量，而不追求在旧轨迹上任意提高拟合度。推导使用经典状态聚合、概率分解和耦合工具，贡献需落实为恢复机制及真实检验。
