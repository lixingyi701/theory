# 反思式 Agent 恢复后的可靠性：研究与实验协议

更新：2026-10-23。目标：ACM TIST Agentic AI 专刊。定位为理论分析主导，以受控仿真解释机制、真实 Agent 检查假设并检验预测。形式化定义、基础推导与未完成的理论问题见[理论框架](recovery_theory_framework.md)。

## 研究问题

Agent 失败后可以回退环境、重建对话、保留反思、局部纠正错误命题或删除含错反思。这些操作改变了它下一次尝试的起点，也可能同时丢掉有效经验。主问题是：纠正或删除含错反思后，后续错误生成、信息保留与窗口更新，怎样改变有限尝试预算下的成功概率和策略排序？跨恢复条件预测用于检验该机制模型。

候选状态由恢复起点可知的任务条件、持久记忆、有序窗口、既往失败轨迹和控制器组成。当前尝试中的错误相关动作尝试、动作生效和反思更新是未来事件，由机制模型积分。局部干预识别机制后，再检验同一组参数能否预测未拟合恢复条件与预算。状态充分性和迁移性均作为实证假设。

当前已完成工程规范化、机制 pilot 和统计预测基线；简单数量／位置模型未显示混合窗口外推优势。下一步先完善机制模型与有限窗口命题，再安排其需要的仿真和参数采样。已有结果保持为建模依据，不继续按记忆组合数量扩展实验矩阵。

## 与近邻工作的关系

[CCRM](https://arxiv.org/html/2605.08563v1)讨论污染与重试成功率；[传播路径研究](https://arxiv.org/html/2608.30198v1)分解记忆和交互路径；[依赖回滚修复](https://arxiv.org/html/2608.10502v1)处理传播后的状态；[RIR](https://arxiv.org/html/2609.18304v3)联合考虑回滚与反思保留；[TraceToChain](https://arxiv.org/html/2604.24579v1)从执行轨迹估计可靠性分布。

本项目将差异放在跨恢复条件的预测：通过真实 Agent 的配对干预识别机制，冻结参数后预测恢复收益。比较重点包括预测误差、校准、目标错误首次在新反思中出现的尝试序号与任务完成率。单独观察错误持续、增加状态数或使用吸收链公式，都不足以支撑这一贡献。

## Agent 与运行状态

当前已接入完整公开 Reflexion、固定 Qwen3-8B 与 ALFWorld，保留作者的尝试、反思触发与最近三条记忆规则，actor 和 reflector 调用配置已冻结。作者 ReAct 是工程参照。

一次完整研究分叉需要保存环境 E、当前交互历史 C、持久反思 M、控制器 J、请求／随机状态 R 和预算 B。状态与事件应区分记忆存储、实际暴露、相关动作尝试与实际生效：错误文本进入 prompt，不证明它导致了某个动作。

事件日志记录 memory-visible、actor-action、trial-end、reflection-write 和 restore。反思写入按原生尝试边界发生。单次失败在仍有重试预算时属于中间事件；最终成功、预算耗尽、格式失败和基础设施故障分别记录。

## 干预与估计对象

从自然反思中选取有公开证据的目标命题。对原生错误可以直接比较保留与纠正；对原生正确内容可以构造目标错误，两类来源分别统计。共享前缀保存事实及证据，评估器在策略之外维护标签。从同一环境、历史和剩余预算分叉：

| 条件 | 持久反思的处理 | 作用 |
|---|---|---|
| 原始反思 | 保留原文 | 测量该任务上的自然后续行为 |
| Sham | 经过相同干预接口，内容不变 | 检查仪器化影响 |
| 保留错误 | 保留原生或构造的目标错误 | 测量污染后的轨迹 |
| 定点纠正 | 恢复共享前缀已验证的目标事实 | 估计目标错误的影响 |
| 丢弃新增反思 | 保留此前记忆，去掉本次新增反思 | 评估错误清除与有效信息损失的共同后果 |

主要因果比较是“保留错误 vs 定点纠正”。丢弃反思还会移除有益信息，因此需记录有效事实保留情况。科学分叉使用独立未来请求和日志，父前缀保持固定；既有 resume 缓存用于故障续跑。

第一阶段统一恢复后的剩余预算，估计同一起点上的残余效应。评估完整恢复策略时，另用总预算统计修复、反思和重放的全部成本。

## 三个待检验假设

H1—H3 是实证检验目标；数学分析首先处理[过程定义与基础模型](recovery_theory_framework.md)，以及[有限窗口中的期望尝试数、预算内增益反例和影响上界](finite_memory_recovery_analysis.md)。这些结果已给出所列假设下的完整证明；正确说明和有效线索的额外作用由仿真及真实校准继续检查。

**H1：状态能概括恢复历史。** 在匹配任务、环境、预算及候选状态后，恢复路径本身是否还提供稳定的额外预测信息？若有，定位缺失状态或非平稳过程。用预设容差及区间判断近似等价。

**H2：事件机制能迁移。** 在校准集估计记忆暴露、相关动作尝试、反思写入和纠正过程；冻结后预测新任务及预先留出的恢复组合或预算条件。评估条件需有校准状态覆盖。

**H3：过程结构改善预测。** 与经验成功率、CCRM 风格尝试模型、同特征 logistic／hazard 模型比较，检验事件结构的预测与校准价值。

## 预测与统计

先明确机制核 $p_\theta(s)=\Pr(Y=1\mid s)$ 与 $Q_\theta(s,s')=\Pr(Y=0,S'=s'\mid s)$，再用

$$
V_0(s)=0,\qquad V_b(s)=p_\theta(s)+\sum_{s'}Q_\theta(s,s')V_{b-1}(s')
$$

计算一次恢复后的 $V_b(\mathcal R(s))$。这是分析工具；论文需要给出恢复收益和排序的结构性结论，而不以采用吸收链计算作为创新。剩余尝试数、任务工作量与调用成本分别处理。

先审计变量可观测性和转移覆盖，再选择最小事件模型。旧四状态模型可作为候选，事件条件化过程或半 Markov 表示按数据需要加入。固定参数的动态规划用于计算给定预算内成功概率；数学计算本身与实证迁移能力分别验证。

校准、模型选择和测试按基础任务分区，同一母任务及所有分支留在同一分区。正式测试留出一个恢复组合和新的预算条件，冻结参数、状态定义、阈值及评估脚本后运行。actor 若能看到预算并改变决策，应将其视为策略条件。

主要指标为完成率及配对增益、目标错误首次在新反思中出现的尝试序号、返工调用／tokens、Brier、log loss 和校准。区间以基础任务聚类计算，动作和分叉数量不替代独立任务数。缺失、提前终止和干预不合格分别列出。Oracle 标签用于离线机制识别；部署预测器另需检验可获取信号的质量。

## 扩展与决策

若完整轨迹显示局部纠正或删除后，目标错误在新反思中再次出现，再通过控制更新器输入，检验旧历史是否影响这一事件；比较更新前移除错误内容与更新后纠正时，匹配可用信息、调用成本和修改权限。随后实现有独立任务分区的 Dependency-Workflow，检查预算可达性与上下文容量，再做短程校准、长程测试。

若定点纠正有效且跨条件预测优于公平基线，继续机制与预测论文；若简单模型同样准确，收缩模型并寻找有价值的边界发现；若状态不足，依据轨迹修正最小表示。各阶段交付见[实验计划](../EXPERIMENT_ROADMAP.md)。
