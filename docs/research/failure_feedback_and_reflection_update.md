# 失败经历、反思记忆与有限预算预测

日期：2026-10-25。接续[有序窗口与状态条件](recovery_state_sufficiency_analysis.md)。[原生语句诊断](../experiments/native-clause-design-20261025.md)在采集前已固定本节所用的过程分解；这里给出完整记号、推导和参数解释。

## 1. 一次尝试的两段过程

固定任务 T、环境重置和 Agent 协议。起始反思记忆为有序窗口 M；成功时停止，失败时生成一段经历 F，再由 reflector 写出新反思 J。F 包含它实际读取的失败轨迹、思考、公开反馈和失败标志，不包含仅供 evaluator 使用的隐藏事实。

记 p(M,T) 为成功概率，μ(dF|M,T,失败) 为失败经历的条件分布，G(dJ|F,M,T) 为反思更新核。成功状态记为 †；失败后窗口变换为 U(M,J)=last_W(M||J)。完整一步核为

$$K_M=p(M,T)\delta_{\dagger}+[1-p(M,T)]\int\delta_{U(M,J)}G(dJ\mid F,M,T)\,\mu(dF\mid M,T,失败).$$

这里的一步仍是一次完整尝试。actor 的多个动作、失败经历和 reflector 的一次更新都在该步内部。若控制器还使用尝试序号，应把它纳入状态或将核写为非齐次序列。

设 B 是一组新反思，例如“明确表达目标错误且没有相反正确说明”的文本集合。失败并写入 B 的联合概率为

$$q_M(B)=[1-p(M,T)]r_M(B),\qquad r_M(B)=\int G(B\mid F,M,T)\,d\mu_M(F).$$

因此，条件于失败的比例 r 与实际联合核 q 不同。存储文本是否含错、执行是否采用该错误、任务是否成功，也分别对应不同事件。

## 2. 两个起点的错误写入差怎样分解

令 M₁、M₀ 是两个恢复起点，省略固定任务下标，令 g_i(F)=G(B|F,M_i,T)。则

$$\begin{aligned}
q_1(B)-q_0(B)
={}&-(p_1-p_0)r_0(B)\\
&+(1-p_1)\int[g_1(F)-g_0(F)]\,d\mu_1(F)\\
&+(1-p_1)\int g_0(F)\,d[\mu_1-\mu_0](F).
\end{aligned}$$

**证明。** 从 `(1−p₁)r₁−(1−p₀)r₀` 中加减 `(1−p₁)r₀`，得到第一项与 `(1−p₁)(r₁−r₀)`。再在 r₁−r₀ 中加减 `∫g₀dμ₁`，即得后两项。□

第一项来自成功后停止所改变的失败概率，第二项来自同一失败经历下记忆对 reflector 的影响，第三项来自失败经历分布的变化。该分解需要两个核在同一可比较的经历空间上定义；观测支持不足时，不能从两组汇总比例分别识别这些项。

一个构造示例可说明比例的差别。若 p₁=0.8、p₀=0.2，且两组失败后的写错概率分别为 0.6、0.3，则 q₁=0.12、q₀=0.24。第一组的失败样本更容易写错，但全部尝试中失败并写错反而较少。这是模型示例，不是 Agent 实验结果。

本批两个面板对应不同对象：完整尝试测量 p 以及自然发生的失败联合结果 q；固定 F*_T 的面板比较 g₁(F*_T)−g₀(F*_T)。后者控制了失败经历，仍没有得到对新 μ 的积分，也没有估计多轮 q。F*_T 中可以保留此前的错误动作或思考，所以“起始反思记忆不含错误”不等于 reflector 的全部输入都不含相关错误信息。

## 3. 机制近似误差怎样进入多轮预测

在同一个可比较的后继状态空间上，令近似模型给出 p̂、μ̂、Ĝ。对某个完整起点 M，假设

$$|p-\hat p|\le\varepsilon_p,\qquad
\operatorname{TV}(\mu,\hat\mu)\le\varepsilon_F,\qquad
\sup_F\operatorname{TV}(G_F,\hat G_F)\le\varepsilon_G.$$

误差取值在 [0,1]。对确定的同一窗口更新 U，有

$$\operatorname{TV}(K_M,\hat K_M)
\le\min\!\left\{1,\ |p-\hat p|+\min(1-p,1-\hat p)
\left[1-(1-\varepsilon_F)(1-\varepsilon_G)\right]\right\}.$$

**证明。** 最大耦合成功／失败指示变量，两个分支不同的概率为 |p−p̂|。两边均失败的概率为 min(1−p,1−p̂)。在该事件上，最大耦合失败经历，F 不同的概率至多 ε_F；当 F 相同时，再最大耦合反思输出，J 不同的条件概率至多 ε_G。因此失败分支的总分离概率至多 `ε_F+(1−ε_F)ε_G`。相同 M、相同 J 经确定映射 U 得到相同后继，故总变差由上述分离概率上界控制。□

这说明单次近似误差既可能来自成功预测，也可能来自失败经历的分布或 reflector 的条件响应。用一个已观察失败经历上的反思调用，不能估计对所有相关 F 的统一 ε_G；只在已采集状态上改善 Brier，也不能得到统一的 ε_p。

若上述一步核误差在预算内所有可到达历史上统一不超过 δ，则使用逐步耦合，预算 b 内的成功概率满足

$$|V_b-\hat V_b|\le1-(1-\delta)^b\le b\delta.$$

两个恢复起点的预测误差分别为 η₁、η₀ 时，恢复收益的误差至多 η₁+η₀。模型需据此说明关心什么预算、允许多大预测偏差，以及相应机制误差是否被数据约束。状态压缩还须满足[有序窗口分析](recovery_state_sufficiency_analysis.md)中的更新闭合和概率条件。

推导使用全概率、状态转移和经典耦合工具。它对本项目的作用是把理论中的误差项对应到可设计的干预与校准对象；这些数学工具本身不作为新颖性声称。

## 4. 对接下来的校准要求

- 在完整尝试上估计成功和失败联合结果，保留任务、种子、窗口与起始文本的对应关系。
- 用固定输入检查 reflector 对记忆的响应，再检查这些响应能否在自然失败经历的分布上共享。固定输入来源仍属于已知开发材料。
- 对含错误、正确说明与冲突的新反思分别保存全文身份；含糊标签的敏感性范围与抽样区间分别解释。
- 将实际窗口长度与顺序用于确定更新；由独立预测检验概率是否可进一步压缩。任务内的重复观测不能替代新任务验证。

这条路线保持原有限预算问题：恢复操作如何改变当前成功机会、失败写回及下一次可见信息。是否增加某个状态变量，取决于它对相应预测对象的增量，而非仅凭新反思出现了不同措辞。
