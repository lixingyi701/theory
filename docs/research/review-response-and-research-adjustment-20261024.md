# 外部审核的逐项核验与研究调整：有限反思记忆的恢复可靠性

日期：2026-10-24。核验基线：研究分支 `research/reflexion-20261022`，提交 [`58980285455a9d91ddb98b90ba5876dc9d9a0aae`](https://github.com/lixingyi701/theory/commit/58980285455a9d91ddb98b90ba5876dc9d9a0aae)。

本文整合项目作者提供的 Claude 审核报告、仓库中的理论与实验记录，以及对五篇近邻论文的原文核验。按原报告的八部分逐项回应，再给出统一的理论问题和后续方案。外部报告的观点采用摘要转述，判断分别标为采纳、部分采纳或纠正；没有把其建议写成已经完成的实验。本次交付为研究评估与计划修订，没有新增模型调用。

## 1. 对项目方向的总体判断

**项目主问题仍然成立，应继续以理论分析为主线。当前需要修订的是一个过度压缩的共享机制模型，以及支撑其外推的采样设计。** 已有负结果不能推出“真实 Agent 无法建模”，也不能保证增加几个变量后就能准确预测。

我们一直要回答的是：在会反思、会重试的 Agent 中，一次纠正或删除记忆怎样改变有限尝试预算内的成功机会？上次将方向调整为“恢复状态的跨条件预测”，把这个问题变成了可以被数据否定的具体主张。现在候选预测失准，说明检验发挥了作用；接下来的责任是定位失准来自哪个假设，提出能被新数据区分的修订。

此前推进中确实有两处需要纠偏：接口问题解决后，统计试验曾先于机制理论；长反思迁移未确立后，虽然有必要做有明确预测的多轮诊断，却不能把诊断扩展等同于已经进入正式验证。现在理论框架、有限窗口证明和受控仿真都已存在，不能继续沿用“只做工程、还没建模”的评价。

**论文仍可围绕机制理论、受控仿真和真实 Agent 干预展开。** 预测与解释是同一论证的两个环节：理论解释哪些因素决定收益，冻结预测检验这些因素是否足以描述真实过程。没有必要现在改成纯现象论文，也不宜把尚未完成的预测优势写成贡献。

可采用的核心问题是：

> 在有限反思窗口中，一次记忆纠正或删除，怎样通过正确说明的保留、旧错误条目的移出和失败后的新反思，改变后续成功概率？什么条件下，这些局部机制能够预测新的恢复条件；什么条件下，压缩状态会给出错误的收益大小或排序？

这比“通用错误迭代理论”具体，也比“观察到错误会被反复写出”更有分析内容。

## 3. 对外部报告八部分的逐项分析

### 3.1 第一部分：研究课题核心——基本合理，边界需更准确

报告正确识别了 ALFWorld、Qwen3-8B、完整 Reflexion 与三条可见记忆。需要补充：当前实验主要在尝试边界重置任务环境和本次交互历史，改变下一次尝试读取的记忆；并没有实现任意执行位置的最优回滚策略。当前预算轴是尝试次数，不能把三次尝试直接叫作长任务长度外推。

理论研究对象可以是一类具有明确更新规则的反思 Agent，实证范围则是固定协议与任务族。二者应同时写清。微波炉规则是识别机制的具体载体，不必成为整个理论的定义，但从这一载体到其他错误类型的适用性仍需相应证据。

### 3.2 第二部分：设计优点——采纳依据，降低无依据的赞誉

固定上游实现、检查实际提示、使用同状态分叉、预先保存预测以及用环境 `won` 判成功，确实减少了结果的多义性。它们使“发生了什么”更可信，却不自动使“为什么发生”和“能否外推”成立。

报告对工程纪律的肯定有依据；“达到顶会水平”“exceptional”“学术界少见”等评价缺少比较标准，不纳入项目结论。50 项离线检查反映代码与协议约束通过，不是 50 项科学假设通过。尤其当前自然反思标签仍由 Codex 全文判读，尚无人工复核；接口审计也没有消除所有无效动作和输出变体。

同状态分叉、存储／暴露／行动的区分和完整日志是证据基础。单靠这些常见方法的组合，还不能宣称独立的方法论创新；其价值要体现在识别了什么新关系、排除了什么替代解释。

### 3.3 第三部分 Problem 1：预测模型失效——实质批评成立，根因判断过强

最重要的负结果是：重复错误起点、两次预算下，纠正与删除分别成功 0/12 和 1/12，差为 −8.33 pp，任务重采样区间 `[-25,0]`；冻结候选为正向 12.06—15.51 pp。它要求暂停把候选模型作为可靠的跨条件预测器。

但这批数据不能单独证明所有候选遗漏变量都有作用，也不足以认定“共享机制假设已经被严格反证”。12 个任务、每条件一个种子、条件选择与参数估计误差共同限制了归因；原预测范围还只是 A 标签不确定性的范围，不是完整预测区间。经验 bootstrap 的上界为零也不能证明总体纠正收益不可能为正。

应区分四类问题：

1. **状态遗漏**：相同错误存在性下，C、具体建议或顺序仍可能影响行动与写回。
2. **状态分布变化**：短规则校准后，实际后继状态变成原生长反思；先前少见的组合可能被频繁访问。
3. **任务混合与失败筛选**：失败后留下的任务组成变了，起点的总体平均参数未必适用于这些轨迹。
4. **估计不确定性**：少量数据估计的成功和更新概率本身有误差，语义标签也有 A 类及待复核部分。

报告把这些列为候选原因是合理的；把它们全部写成已识别的根本原因则过早。特别是“同一 R 在不同任务作用相反”也不准确：R 是各任务自己的原生反思残余，并非跨任务逐字相同的一段话。这些路径差异有诊断价值，还不是保持其余条件不变的机制隔离。

### 3.4 第三部分 Problem 2：理论与实现的鸿沟——部分问题已经修正

**逐动作更新与尝试边界更新：** 这是早期需要纠正的问题，当前过程定义已经修正。应保留旧记录的历史身份，在论文主线只使用与原生 Reflexion 对齐的更新时钟，不能把旧草图再当作当前执行模型。

**任务异质性与非齐次性：** 采纳检查要求。固定权重并不意味着压缩后的转移概率恒定，全文输入和失败任务组成都在变。但无需先验宣布必须用任意非齐次模型；应先检验在相同任务和状态下是否还有可重复的轮次差异。

**成功与预算耗尽：** 成功吸收与有限时域截止已经进入当前递推。预算耗尽首先是观测／决策时域的终点，不必当作另一个随机竞争风险来重建模型。若任务中另有不可恢复终止事件，再显式加入相应出口。

**oracle 信息：** 报告提出的区分有价值，但不是已经发生信息泄漏的证据。早期“原生正确命题→改错→还原”的注入流程，与后来的构造 E/C 规则实验应分别说明。后者研究的是提供一条正确规则与错误规则的后果，不能一概称为逐条还原原生反思。纠正相对删除本来就可能保留额外有用信息，这是研究机制之一。只要明确外部干预者掌握什么、规则来源是什么，就可以研究这种因果对比；不能由此宣称 Agent 会自行发现正确规则。将隐藏位置、参考动作序列等传给 actor 则是另一回事，当前研究协议禁止这种输入。

### 3.5 第三部分 Problem 3：样本量与统计功效——接受主要提醒，重做计算

报告正确指出，任务内种子不是独立任务，四个场景限制跨场景推断，正式验证仍缺样本量设计。但“pilot 没完成使命”过于笼统：现有阶段已经排除了实现问题，发现不同事件不能合并，也识别了候选预测的薄弱处。探索性诊断允许小样本；问题在于不能用它替代正式确认性结论。

它给出的样本量公式和结果不一致：

$$
2(1.96+0.84)^2(0.4/0.15)^2\approx111.50,
$$

而不是 56。在通常的两个独立组、等样本数和共同标准差近似中，这还是每组样本数。配对设计若把 $\sigma_D=0.4$ 定义为**任务级配对差的标准差**，则一阶正态近似为

$$
n\approx(1.96+0.84)^2\sigma_D^2/\delta^2\approx55.75.
$$

这解释了“56”可能来自哪里，却不能证明本项目需要 56 个任务。报告使用的是背景交互的区间，目标却变成纠正／删除收益；两者方差不可互换。即使粗略按正态近似倒推，半宽 0.2917、12 个任务对应约 0.516 的任务级标准差，也不是 0.4；bootstrap 分位数更不应这样反推正式方差。

正确做法是先固定一个主要估计量与最小有意义差异，再用其任务级配对结果、种子变异和场景结构做功效／区间精度模拟。对于一次配对二元结果，$D=Y_C-Y_D$，其方差取决于不一致配对概率 $q_{10}+q_{01}$ 和均值差，而不只取决于两个边际成功率。每任务多种子时，先明确目标是任务期望差还是一次随机执行差，再按对应层次估计。

“样本不足就降低效应门槛”也应修正：如果想检测更小的差异，通常需要更多样本。资源有限时，应缩小推断范围、提高可分辨的最小效应，或坦率报告区间精度，而不是调整标准直到得到显著结果。

### 3.6 第四部分 Problem A：新颖性边界——重叠存在，不等于问题已被做完

报告关于“错误潜伏、记忆修复、吸收链都已有工作”的提醒合理。它从这些关键词重叠直接跳到贡献过窄，则没有充分比较预测对象、假设、干预和验证方式。第 4 节给出逐篇比较。

预印本是需要认真引用和比较的公开工作；尚未经同行评审，不代表其贡献可以忽略。反过来，摘要中的广泛创新声明也不等于已经证明所有相关结论。我们的空间来自具体增加了哪些知识，而不是预印本地位更低，也不是简单换成 ALFWorld 或 8B 模型。

### 3.7 第四部分 Problem B：研究对象不清——需要聚焦，但不存在报告描述的二选一

不训练 reflector、不提出最优恢复策略，都不妨碍研究给定系统的可靠性。理论／测量论文可以解释和预测既有机制，不一定要带来新的修复算法。

真正需要固定的对象是**干预后有限预算收益与其可预测条件**。状态表示、错误写回和任务差异都是解释这一对象的变量。不要在每次负结果后另起“认知诊断”“概率校准”“修复算法”三个并列主题。

“扩展状态就必然接近全文模型，保留简单模型就必然只能写弱案例”是假两难。有限有序窗口可以保留必要更新结构，同时用少量参数描述行动与写回；在明确域内获得准确近似也有价值。模型的复杂度应由机制对照、覆盖和独立预测增益约束，而不是越小越理论、越大越不理论。

### 3.8 第五部分：解决方案——保留方向，纠正若干设计

| 建议 | 处理 | 理由与调整 |
|---|---|---|
| 加入 C 和冲突顺序 | 部分采纳 | 是合理候选，但仅有 `r+has_correct+order` 未必能确定窗口更新；见第 5.2 节反例 |
| 每任务分别估计概率 | 部分采纳 | 适合作为已知任务诊断；新任务没有自己的校准结果。正式预测考虑公开任务特征或部分共享的层次模型，不能把 task ID 当作外推能力 |

### 3.9 第六部分：投稿可行性——当前证据未齐，“50%”没有依据

尚未完成独立验证、重要候选预测失准、真实文本状态仍需修订，这些都是投稿准备不足的具体原因。“可行性 50%”没有可校准的录用模型或审稿依据，应删除。四个场景和一个模型限制主张范围，却不能机械地换算成期刊录用概率。

原时间表还把正式样本量实验安排在状态诊断完成之前，顺序不合适。应先确定估计量与候选机制，再定样本规模、冻结参数和验证；写作可以与这些工作并行，不必等到全部实验结束才开始。

Workshop、短文或拆成两篇可以在最终证据不足时考虑，但当前没有必要预先作“降级”决定。将一个尚未闭合的机制故事拆开，也可能使两篇都缺少核心结果。

### 3.10 第七、八部分：战略建议与个人评价——接受聚焦，不接受动机推断

用一份简短贡献声明固定主张、请导师／合作者检查、预设停止扩展的条件，这些建议有用。“研究新手通病”“新颖性焦虑”“过度追求完美”是对作者心理的推测，不是从仓库能验证的研究结论。

“科学发现缺失”也过于绝对。现在已有可证的条件关系、机制反例和实际预测偏差；缺少的是经过独立检验、足以构成论文核心的完整结论。此前工程投入不是继续投入的充分理由，也不是必须止损的理由。后续每一步要根据能否解决一个尚未解释的机制问题来判断价值。

CCRM 的低拟合误差不能直接与本项目尚未复现的前瞻预测相比：用 pass@3 求参数后再还原 pass@3，与先在别的条件估参数、再预测 pass@3，是不同难度的任务。这是证据设计差异，不是对该论文全部理论的否定。反过来，本项目采用更严格检验，也不自动产生新颖性；需要最终拿出机制结论和可用的预测范围。

论文可争取的贡献集中为三项：

1. **有限记忆恢复的机制分析。** 将局部纠正和整条删除表示为不同的记忆变换，分析信息保留、窗口移出与失败写回如何共同决定收益及可能的排序变化。
2. **与干预对应的状态条件。** 给出哪些信息被压缩后仍能递推、遗漏何种差异会改变预测，以及误差何时足以改变恢复排序。
3. **理论到真实系统的验证。** 用受控仿真验证模型内关系，用同状态干预检验必要机制，再用新任务与留出恢复组合检查冻结参数的预测。

经典马尔可夫链递推、Jensen 不等式、总变差耦合和配对实验都是可借用的工具。新贡献要落实在本问题的机制关系与证据上。单独报告“旧条目退出但新反思仍含错”，或只给旧工具换名称，确实不足以支撑当前目标；这部分应接受报告的提醒。

## 5. 当前模型怎样调整，才不是不断加变量

### 5.1 保留三个层次，明确各自接受什么检验

| 层次 | 内容 | 现有结果的影响 |
|---|---|---|
| 过程定义 | 固定任务、环境重置、读取有序窗口、行动、失败后追加一条反思 | 已与程序对齐，是研究对象的定义 |
| 条件理论 | 在明确 p、更新核与共享假设下推导有限预算收益、期望尝试数和界 | 仍按其假设成立；需要的是检查真实过程满足哪些条件 |
| 经验实例 | 用当前少量校准数据、错误存在性和共同参数近似真实机制 | 重要预测已失准，必须修订与重新验证 |

“有一个完整状态总能写出递推”本身没有足够贡献。研究必须进一步给出可估计的结构、具有解释力的结论，以及误差或适用范围。实际目标也不是把已有 72 条轨迹拟合好，而是在不使用新验证结果的情况下预测它们所属的未来条件。

### 5.2 `r + has_correct + conflict_order` 仍可能丢失更新信息

考虑三条窗口、从旧到新排列的两个状态：

$$
M_A=[C,N,E],\qquad M_B=[N,C,E].
$$

它们的 `r=3`、`has_correct=1`，相对顺序也都是 C 先于 E。追加一条 N 后却变成

$$
M_A^+=[N,E,N],\qquad M_B^+=[C,E,N].
$$

一个失去 C，另一个仍有 C。因此，这三个特征不足以确定下一次该特征状态。如果 C 影响后续行为或更新，它们就不能不加假设地视为同一马尔可夫状态。

建议在理论与程序中保留**实际长度和有序条目类型**，空位与 N 分开；由它计算 r、C 的位置和 E/C 顺序。严格 FIFO 下，这样至少能准确表示条目移出。全文到类型的语义压缩是否足够，仍由实验检查。

状态保留多少信息与拟合多少参数是两件事：不需要给每个窗口一个自由转移矩阵。可以预先限定小规模参数族，例如成功概率与失败更新各有一组共享系数，依次检查 E、C、顺序是否带来增量。保留原模型作为最小基线；没有状态覆盖的系数不作已识别参数。原生 A、同条内部矛盾和其他建议也不能强制压为安全的 N。

### 5.3 两次预算的收益分解：把需要估计的量说清

固定任务 T，令操作 $o\in\{C,D\}$ 分别为纠正与删除，$M_o$ 是操作后的记忆。记首轮成功率为 $p_o$，$q_o(j)$ 为“首轮失败并写入完整反思 j”的联合概率，$g_o(j)$ 为该反思追加并截取窗口后，下一次尝试的成功概率。在重置后所需控制状态固定的条件下，

$$
V_2(M_o)=p_o+\sum_j q_o(j)g_o(j).
$$

若控制器还保留其他影响续行的信息，应把它和 j 联合纳入后继状态。上述和式可以相应改为积分。对两种操作相减、加减 $\sum_j q_C(j)g_D(j)$，得到

$$
\Delta_2=(p_C-p_D)
+\sum_j[q_C(j)-q_D(j)]g_D(j)
+\sum_jq_C(j)[g_C(j)-g_D(j)].
$$

三个项分别对应首轮成功差异、失败后写入分布的差异、同一新增内容在不同剩余窗口中产生的后继机会差异。这是精确的概率分解；三个项不自动成为独立可识别的因果中介效应，某些跨分支 j 也可能没有观测支持。

已有简化式

$$
\Delta_2=a(p_0-p_1)
$$

是特例：两种起点首轮都含 E、共享同一写入机制，且后继成功只依赖有无 E；$a$ 是首轮失败且新反思不含 E 的联合概率。纠正保持窗口满长，使旧 E 提前退出，删除后则要多一次追加才退出。

这条式子直接说明，旧 E 提前退出只是条件之一。要有正收益，还需要 $a>0$，以及目标错误不再可见时确有更高的成功概率。当前候选已经包含重述；下一步要查明的是 a、成功差或共享条件哪个失准，而不是再加入一个已经存在的“错误重述模块”。

### 5.4 任务异质性会影响恢复收益，不能仅按 task ID 拟合

若上述简化关系在各个任务内成立，令 $d_T=p_{0,T}-p_{1,T}$，则总体收益为

$$
\mathbb E_T[\Delta_{2,T}]
=\mathbb E_T[a_Td_T]
=\mathbb E_T[a_T]\mathbb E_T[d_T]+\operatorname{Cov}_T(a_T,d_T).
$$

证明就是期望乘积的协方差恒等式。它指出一个可检查的问题：更容易在失败后写出不含 E 反思的任务，是否也是从不含 E 状态中获益更大的任务？直接相乘两个总体均值会遗漏这种关系。当前数据没有可靠识别这项协方差。

已有固定任务混合公式

$$
V_b=1-\mathbb E_T[e_{M_T}^{\top}Q_T^b\mathbf1]
$$

也要求先在同一任务内递推，再平均；一般不等于把平均转移矩阵取 b 次幂。简单固定成功率特例中的池化乐观偏差，不能扩展成所有记忆过程、所有恢复收益都有同一偏差方向。

正式模型可比较：完全共享机制、少量起点可获取任务特征、带部分共享的任务差异。对新任务使用层次模型时，应对未知任务效应积分并传播不确定性，不能使用验证任务事后估得的 task ID 系数。每任务独立拟合只作已知任务诊断上限。

### 5.5 用预测容差限制扩展，而不是追求全文的精确充分性

若把成功也作为状态，真实过程与近似过程在所有将访问的相应状态／历史上的单步分布总变差不超过 $\varepsilon$，逐步耦合给出

$$
|V_b-\widehat V_b|\le1-(1-\varepsilon)^b\le b\varepsilon.
$$

理由是每一步在此前未分离的条件下，以至多 $\varepsilon$ 的概率发生首次分离；b 步未分离概率至少为 $(1-\varepsilon)^b$。预算内成功事件的概率差不超过路径分离概率。

两个恢复起点若分别有误差界 $\eta_C,\eta_D$，则

$$
|\Delta_b-\widehat\Delta_b|\le\eta_C+\eta_D.
$$

因此，只有预测差超过该误差范围，才能据此给出有保证的排序。Brier 改善和小样本平均误差都不是统一总变差上界，不能把本式直接变成当前实证的数值保证。

它提供的是设计原则：事先规定关心的预算与概率误差，检查哪些遗漏足以改变决策，保留必要变量。若同类型不同文字的差异已超出容差，应扩大不确定性、限定适用条件或增加有机制依据的状态；不能无限添加自由变量直到旧数据拟合成功。这些概率工具是经典工具，其问题价值取决于我们能否把误差来源与可实施干预对应起来。

## 6. 调整后的实验与理论推进顺序

本节是后续设计，不是本次已执行工作。旧批次额度均已关闭；本次不启用 134 个留出任务。

### 阶段 A：先完成一份稳定的理论与贡献说明

将第 5 节的状态更新反例、收益分解、任务混合关系整理到后续理论修订中，并把以下内容逐一绑定：变量定义、可观测量、所需假设、可识别方式和反例。已有证明、构造仿真和真实测量分别标明。

先固定三种竞争解释：C 具有错误存在性之外的作用；E/C 顺序改变成功或写入；固定任务差异导致池化外推偏差。背景全文的其他影响保留为残余诊断，不立即用高维全文嵌入替代这三个问题。

### 阶段 B：最小同状态对照，先检验新增维度

| 对照 | 识别目标 | 不能从它直接推出什么 |
|---|---|---|
| `[C]`、`[N]`、空历史 | C 相对通用文字的作用，以及一条通用记忆相对空历史的作用 | 不能将 C−空历史全部归于目标语义 |
| `[E,N,C]` 对 `[E,N,N]` | 固定旧 E 和条目数后，最新 C 的增量 | 这本身不是顺序效应实验 |
| 有条件增加 `[C,N,E]` 对 `[N,N,E]`，与上一行联合比较 | 比较 C 在 E 之前／之后的增量；同步保留每种背景的位置控制 | 不能仅交换两句话就宣称隔离了所有位置与长度因素 |
| 同一已保存失败记忆：目标语句保留／纠正／删除，其余文字保留 | 新写入的目标语句如何影响下一次行动与成功 | 句级删除不同于整条删除；两者窗口对齐效应不同 |
| 如需定位 reflector：固定同一失败轨迹和提示，仅干预其允许变化的记忆输入，再生成反思 | 分辨输入记忆对写回的影响 | 不能用不同失败轨迹的 E 比例直接识别 critic 的因果作用 |

首批核心只需前两行的五种起点。新种子用于估计任务内随机性，同一任务各条件共用配对设计；样本数与调用上限在执行前按主要估计量冻结。顺序和 critic 诊断按前述假设需要触发，不同时铺开全部组合。

actor 与 reflector 继续使用已固定的模型、模板和环境。正式比较同时报告成功、目标动作尝试、环境接受与新反思类型；不能只比较最后成功数。C/E 措辞、token 长度和位置的具体差别公开记录，N 不当作语义上的零作用。

### 阶段 C：重新校准，并在新开发任务上淘汰状态候选

原 12 个加热任务继续承担机制定位。用 train 中未参与本轮选择的新任务／场景作候选选择与确认，所有同源分支保持同分区，同场景整体分区。根据状态覆盖拟合少量共享参数，不为纠正与删除各建一套无关参数。

概率建模可继续用成功及失败后 E/C/U/A 的联合分布，或者分开拟合成功率与失败条件更新核，但两种方式必须回到同一个合法单步概率模型。分别检查成功与更新误差，不能用五类联合 Brier 的改善掩盖成功预测恶化。

比较基线包括：常数／条件比例基线、原错误存在性模型、包含相同起点特征的直接概率模型，以及有明确适用假设的重试模型。对同特征模型的比较用于区分“特征变丰富”和“过程结构带来价值”。无需为完成此比较强行复现所有以提高成功率为目标的回滚算法。

### 阶段 D：先设计精度，再冻结独立预测

正式检验至少区分两个目标：新任务上的成功概率预测，以及新的恢复／预算组合上的收益预测。允许使用同样的单步状态覆盖来预测未拟合的状态序列；若新操作会产生校准中从未覆盖的状态，应标为额外外推，不能和覆盖内组合混在一起。

先固定一个主要预算与主要收益对比，明确最小有意义差异、预测误差容差和配对统计方法，再进行样本量模拟。保留完整估计不确定性，包含参数、任务抽样和语义未定性；不把 A 上下界当作完整预测区间。

134 个 holdout 继续作为封存资源。使用前固定资格与场景权重；四场景结果可描述这些场景中的条件表现，不能据此声称覆盖广泛场景总体。需要增加场景多样性时，从可用开发数据另行建立场景互斥分区，而不是拆开同一 holdout 房间反复调参。

### 阶段 E：预设修改与停止规则

| 新证据 | 研究决策 |
|---|---|
| C 有重复且可迁移的增量，顺序无明显增量 | 保留 C、去掉不必要的顺序参数；区间精度不足时继续报告未定，而非认定零效应 |
| 顺序主要改变写回，而非当前成功 | 更新核使用顺序，成功模型不必照搬相同复杂度 |
| 任务内预测可用，池化预测失准 | 保留任务差异并检验新任务积分预测；不退回每任务事后拟合 |
| 类型相同的原生文本仍产生超过预定容差的差异 | 承认该状态在这类文本上不够，提供对应反例与域限制；不继续无上限增加特征 |
| 新模型在独立任务／组合上改善预测，机制对照吻合 | 完成理论—仿真—真实验证主线，再选择与结论有关的一项外部复核 |
| 完成一次预定最小修订后，仍只能靠逐条件调参解释结果 | 停止“共享预测已成立”的主张，评估以系统性的失效条件和实证边界组织论文；此时再讨论投稿形式 |

同一批数据用于提出新变量后，就属于开发证据。不能把它再次评为“新的独立验证”。延长预算或切换第二模型也必须服务于具体结论，而不是用更多实验替代理论缺口。

## 8. 形成论文时应保留和删去什么

保留“有限反思记忆中的恢复收益及其可预测条件”作为主线，可暂用工作标题：

> **Recovery in Finite-Memory Reflective Agents: Mechanisms, Predictability, and Limits**

论文按“问题与近邻—过程定义—有限窗口结论—受控仿真—机制干预—冻结预测与边界”展开。工程审计放到方法说明和复现附录；贡献声明明确列出哪些已证明、哪些已观测、哪些仍待独立验证。

项目可以这样向读者介绍：

> 我们先用固定大模型和完整 Reflexion 构建一个会反思、会重试的 Agent。在 ALFWorld 的相同任务起点，为它提供受控的错误规则、正确规则或不同记忆窗口，再比较纠正一条命题与删除整条反思的后果。失败后让 Agent 自己生成下一条反思，观察正确说明是否仍被保留、旧错误何时退出、新反思写了什么，以及任务在有限次尝试内是否完成。理论分析这些机制怎样共同决定恢复收益，仿真检查推导，真实 Agent 实验则检查假设，并检验冻结参数能否预测新的任务和恢复条件。
