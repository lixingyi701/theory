# 持续任务差异与有限预算预测

日期：2026-10-25。本文说明[新任务共同校准](../experiments/shared-calibration-design-20261025.md)为什么保留跨轮不变的任务潜变量，接续[有序窗口分析](recovery_state_sufficiency_analysis.md)中的任务混合命题。

## 1. 同一任务失败后仍是同一任务

任务难度影响尝试成功的概率。一个任务首次失败后，环境虽恢复到起点，其难度并没有重新随机抽取。若把全体任务平均后的单步概率直接递推，就可能低估连续失败的相关性。

考虑最简单的特例：记忆不影响成功，任务具有固定成功概率P；给定P后各次尝试独立。预算b下的总体成功概率为

$$V_b=1-\mathbb E[(1-P)^b].$$

先平均再递推得到

$$\widetilde V_b=1-(1-\mathbb E[P])^b.$$

对整数b≥1，函数`(1−p)^b`在[0,1]上凸，Jensen不等式给出`V_b≤Ṽ_b`。当b=2时，偏差恰为

$$\widetilde V_2-V_2=\operatorname{Var}(P).$$

**证明。** 展开`V₂=2E[P]−E[P²]`及`Ṽ₂=2E[P]−(E[P])²`，相减即得。□

例如，两类任务各占一半，P分别为0.1和0.9。平均单轮成功率都是0.5，但两次成功率是0.59；按平均概率递推得到0.75，差0.16。该例为数学构造。

## 2. 加入反思窗口后的共同核

用θ表示一次抽取后持续不变的任务潜类，M表示可见有序反思窗口。共同模型给出`pθ(M)`与失败条件更新`Gθ(j|M)`，窗口追加操作为U。总体预算概率必须先在θ内递推：

$$V_{b,\theta}(M)=p_\theta(M)+(1-p_\theta(M))\sum_jG_\theta(j\mid M)V_{b-1,\theta}(U(M,j)),$$

$$V_b(M)=\sum_\theta\pi_\theta V_{b,\theta}(M).$$

对已经观察到的失败与新反思j，潜类权重更新为

$$\pi'_\theta=\frac{\pi_\theta(1-p_\theta(M))G_\theta(j\mid M)}{\sum_a\pi_a(1-p_a(M))G_a(j\mid M)}.$$

因此，在潜类模型内，`(M,π)`足以表示下一步预测所需的记忆和任务信息。即使两个轨迹当前具有相同M，连续失败经历不同也可能使π不同。只保留M的总体过程通常不满足齐次共享核假设。

本批小候选令G在潜类间共享，潜类只改变成功截距。于是观察失败后的权重变化来自`1−pθ(M)`；给定M与失败，j不额外识别θ。该候选回答成功难度差异是否有解释力，更新机制的任务差异仍留给误差分析。

## 3. 与恢复收益的联系

对两个恢复后的起点M₁、M₂，预测收益为

$$\Delta_b=\sum_\theta\pi_\theta[V_{b,\theta}(M_1)-V_{b,\theta}(M_2)].$$

同一任务在两个分支使用同一潜类。已有两次预算特例`E[a_Td_T]=E[a_T]E[d_T]+Cov(a_T,d_T)`也说明了这一点：错误未写出的概率与无错状态的成功优势可能在任务间相关，平均参数的乘积会丢失这种关联。

本批将无任务差异与持续随机截距放在相同特征、数据分区和预算下比较。若随机截距改善整场景留出的成功预测，就为保留这种任务差异提供依据；若没有改善，仍按预定简约规则选择。共同核对具体任务可有不同条件概率，同时共享少量机制参数。

以上使用经典混合分布、条件概率和凸性工具。研究中的作用是明确真实Agent参数应怎样进入预算预测，并使后续校准能区分窗口信息不足与任务混合偏差。
