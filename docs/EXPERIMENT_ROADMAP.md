# 实验路线与投稿安排

更新：2026-10-22。主线为恢复状态的跨条件可靠性预测；投稿目标为 ACM TIST Agentic AI 专刊，截止日期 2027-01-31。

| 阶段 | 工作与交付 | 完成条件 |
|---|---|---|
| 1：Agent 与观测 | 接入完整作者 Reflexion；固定 actor／reflector、重试、成功判定与成本；补齐事件日志 | 开发能力检查与 no-hook／sham 检查完成，能追踪事实来源及反思边界 |
| 2：分叉与机制 pilot | 相同前缀比较原始、sham、保留错误、定点纠正、丢弃新增反思 | 环境／历史／预算匹配，分支独立；获得复发、行为采用与返工轨迹 |
| 3：正式校准 | 根据 pilot 的独立任务方差确定样本量；比较最小事件模型与公平预测基线 | 变量、模型、测试条件、指标与统计脚本冻结 |
| 4：跨条件验证 | 在新任务、预留恢复组合和预算上预测并执行验证 | 报告预测误差、校准、配对恢复收益及区间 |
| 5：适用边界 | 根据主结果补充第二骨干；实现受控工作流并检验长度外推 | 明确迁移成立与失效的条件 |
| 6：论文与复现 | 汇总机制、预测、边界与运行工件 | 完成期刊正文、附录和复现说明 |

开发集 dev12 用于实现诊断；正式样本量由 pilot 方差、希望区分的效应和调用成本决定。134 holdout 保持封存，使用前冻结其用途与四场景结构的统计解释。

## 时间安排

- 11 月：完成 pilot、正式采样设计与校准；同步撰写问题和方法。
