# 实验路线与投稿安排

更新：2026-10-23。主线为恢复状态的跨条件可靠性预测；投稿目标为 ACM TIST Agentic AI 专刊，截止日期 2027-01-31。

执行进展：作者 Reflexion、模型／工具[接口规范化](experiments/interface-normalization-20261023.md)及工程配置冻结已完成。目的地绑定 pilot 完成四任务五条件分叉，各条件成功 2/4；[操作前提扩展](experiments/precondition-pilot-20261023.md)进一步获得了错误采用、反思重述与纠正有效的轨迹。三个新目标的原始错误成功 0/3，纠正与丢弃各 1/3。[首次冻结预测](experiments/state-prediction-20261023.md)完成 28 个同质窗口校准、8 个混合窗口验证；数量／位置模型未优于总体均值。下一步补充冲突状态和独立任务数据。

| 阶段 | 工作与交付 | 完成条件 |
|---|---|---|
| 1：Agent 与观测 | 接入完整作者 Reflexion；固定 actor／reflector、重试、成功判定与成本；补齐事件日志 | 开发能力检查与 no-hook／sham 检查完成，能追踪事实来源及反思边界 |
| 2：分叉与机制 pilot | 相同前缀比较原始、sham、保留错误、定点纠正、丢弃新增反思 | 环境／历史／预算匹配，分支独立；获得复发、行为采用与返工轨迹 |
| 3：正式校准 | 根据 pilot 的独立任务方差确定样本量；比较最小事件模型与公平预测基线 | 变量、模型、测试条件、指标与统计脚本冻结 |
| 4：跨条件验证 | 在新任务、预留恢复组合和预算上预测并执行验证 | 报告预测误差、校准、配对恢复收益及区间 |
| 5：适用边界 | 根据主结果补充第二骨干；实现受控工作流并检验长度外推 | 明确迁移成立与失效的条件 |
| 6：论文与复现 | 汇总机制、预测、边界与运行工件 | 完成期刊正文、附录和复现说明 |

开发集 dev12 用于实现诊断；正式样本量由 pilot 方差、希望区分的效应和调用成本决定。134 holdout 保持封存，使用前冻结其用途与四场景结构的统计解释。

校准的时间单位、可观测变量、恢复留出方式与参数冻结流程见[校准与验证细则](experiments/calibration-plan-20261023.md)。

## 接下来的研究顺序

1. 扩充状态覆盖：首轮同质窗口已完成冻结外推检查，ECC／CCE 成功 0/8。下一轮在校准中加入 EC／CE 等冲突窗口，估计交互，并在新的基础任务上检验其他组合。保留总体均值、数量、位置模型及公平任务特征基线。
2. 扩大独立基础任务的事件覆盖。当前三个合格目标均来自加热，先报告整个抽样池的资格率，再扩展操作前提、观察事实与搜索覆盖。原生错误与人工构造的错误分层记录；任务资格在后续结果前固定。
3. 校准尝试级机制。分别估计成功概率，以及失败后新增反思重述错误、明确纠正、未提及／不明确的概率；三条窗口的推进由作者规则计算。纠正或丢弃后重新产生的错误属于回写事件，未提及不能直接标为纠正。
4. 冻结状态、参数与评估。除记忆位置，还检查起点已知的任务类型、首次失败轨迹与竞争错误是否提供增量信息。采用、动作接受和未来手持状态用于解释机制，预测时不能当作已知输入。
5. 在新基础任务上检验未拟合的恢复组合与一／两次剩余尝试。正式基线使用同样的起点信息；已知任务的经验成功率只能用于开发诊断。134 holdout 的用途、资格规则与四房间解释在首次调用前固定。

下一关是独立任务上的预测误差和自然反思回写覆盖。校准的 19 个失败更新已逐项复核，正式转移估计还需更多独立任务。模型复杂度依据这些数据增加；第二骨干和多环境扩展在主结果成立后开展。
